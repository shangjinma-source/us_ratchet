# MTCH 2020 重组：不能使用 3.502 普通拆股修正

## 已核事实

[Nasdaq ECA2020-109](https://www.nasdaqtrader.com/TraderNews.aspx?id=ECA2020-109) 原始 HTML 已保存。旧 MTCH（CUSIP 57665R106）最后交易日 2020-06-30，7/1 新 MTCH（57667L107）上市。同名 ticker 跨越真实身份变更。

[SEC 完成公告](https://www.sec.gov/Archives/edgar/data/1800227/000110465920080610/tm2022502d7_ex99-1.htm) 明确两条不同权益路径：旧 Match 公共股东每股取得一股新 Match，另可选择 3 美元现金或 0.0337 股新 Match；旧 IAC 股东每股取得一股新 IAC 和 2.1584 股新 Match。不能混淆两种前身。Yahoo 的 3.502 既不是这些真实换股比例，也不能作为旧 MTCH 母股数量变化；该供应商因子的精确计算来源仍未认证。

## 实际行情坐标验证

仅对已下载的 tsaustin ZIP 再做一次本地流式提取，无额外行情下载，取得 MTCH/IAC 各 134 行（2019-12-30—2020-07-10）。MTCH 原始 close 与已存 Yahoo 133/134 日在半美分内一致，唯一 7/6 为 94.78 对 94.70。事件邻日两源一致：旧 MTCH 6/30 为 107.05，新 MTCH 7/1 为 105.67。同期旧 IAC close 为 323.40，新 IAC 为 106.71。故当前 MTCH close 序列跟随旧 Match 公共股东前身，不能将 2020 年前段乘 3.502 来恢复所谓名义价。两数据源都没有将本次 3 美元选择权自动纳入 close，归档 close_adjusted 也不应直接当作可靠总回报。

## 可精确实现的训练口径（尚未实施）

1. 身份映射必须标注旧 MTCH → 新 MTCH，日期 7/1。保留原始 close 和官方权益分开，不能删除候选股或将事件伪装成普通 split。
2. 若沿用全域明确的价格回报训练，边界比率为 105.67/107.05，但这排除了真实额外对价，只能叫 price-only。不是已经解决经济回报的一致性。
3. 若固定现金选择路径，事件边界经济 gross 为 (105.67+3)/107.05。此公式可以由当时已知公开条款和当日 close 精确算出，且截至 2020-12-31 训练日不存在未来信息。它不证明现金当天到账。后续若现金仍作为应收或留存现金，单份原股财富为 P_t+3，后续 gross 应为 (P_t+3)/(P_(t-1)+3)，直至明确处置政策；不能只补边界一天后又假装现金已经再投资。
4. 若固定股票选择路径，边界为 1.0337×105.67/107.05，之后继续持有新股；仍需处理整股/零股或明确训练用连续资产单位。不应比较两种选择后挑收益更高者。两路径均不得当成实盘到账证明。
5. 最小建议：在训练编译器增加经审核的 identity-transition return 输入，明确选择与现金保留政策，保留名义 decision_cost 不变；该字段只影响过去训练比率，不能覆盖执行报价。先用手算边界、事件前后日、常规日前后回归以及拒绝3.502伪拆股负例验证。若仅要保持既有 price-only 训练，可先单独认证身份链及不改价例外，但需 root 确认口径，不暗中声称总回报已处理。

范围外：没有实际持仓跨事件的回测无需汇丰历史到账单；训练收益链的政策选择仍须明确，不能因具体券商资料未知全局阻塞。完成事实和假设必须分栏记录。
