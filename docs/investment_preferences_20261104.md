# 本轮投资偏好与策略评价口径

用户明确：上涨时能够持有；下跌接近30%会动摇。30%当前是心理警戒参考，不是已授权上线的机械止损阈值，也不承诺未来回撤可被精确限制。历史71%或68%回撤不符合其承受范围，不能因最终年化高就推荐采用。

用户可以接受熊市判断导致错过反弹、卖出后股票继续上涨；重视及时止盈、保留已有利润。不希望多年低于累计投入，最后依赖2026年一轮牛市获得大部分收益。不能把这些偏好简化为赚一点就卖、提前知道熊市，或保证任何时候都不亏损。

评价顺序：先做相同日期、现金流的纳指ETF基准对照；除年化与最大回撤，还要显示水下时间、恢复时长、低于累计投入的时间、2022年压力及剔除2026后的结果。复杂策略若不能带来足够收益或持有体验补偿，应认真考虑更简单的方案，而不是为了保留自研策略无限优化。

当前顺序：只用现有数据做轻量算术对照，暂不启动新的参数搜索。随后再讨论少量固定组合防御/个股盈利保护规则，每项明确代价、误判和重新买入方式。此前对年化的重视仍需展示，但不能覆盖最新明确的回撤及持有体验要求；涉及降低收益的方案应给用户具体交换幅度。

现金流示例已由用户确认：2020年底初始5万美元，2021至2026每年首个交易日再追加5万美元，总投入35万美元。截至已有最后数据2026-07-30。已给结果只是两独立段策略净值按比例串联的情景估算，不是连续整股重跑，也不是未来收益预测；用户要求不为此耗费大规模计算。
