# 保存候选重排：运行接口接入

2026-10-25 收尾工程进行中。本文记录实现契约，不表示新策略已在生产启用。

原月目标的 `payload`、`target_id` 和选股决策保持原样。独立提案按原目标保存；读取时重新核对保存内容。写入中断后可以重放原生成请求恢复提案，不重新选股；缺失提案时不返回可执行建议。

前端月目标响应同时提供原 `targets` 和新 `proposal_targets`。新版本有 `proposal_id` 时必须使用后者，不能在缺失时退回原目标。日常建议请求必须包含 `expected_revision`、`target_id`、`expected_proposal_id`；响应必须对应同一组三个编号。图表缓存也包含提案编号。

数据准备域包括提案股票、实际持仓、未完成订单以及风险库中的峰值和已退出股票。身份、价格单位和月内完整历史缺失时等待。公开行情与公告检查保留原有条件性限制，不将来源字节一致性宣称为绝对真实性或完整公司行动覆盖。审核使用实际当前时刻，不倒填历史审核时间。

建议生成日志保存独立提案编号；写日志后再次检查账户、目标、提案及风险和报价有效期。失效时清空可执行订单。日志的返回状态是写入时的检查结果，最后复核可能进一步降为等待，因此日志不证明页面实际展示或成交。

当前新增模块仍须完成运行来源读取器、风险投影、每日建议组合、图表服务及服务器发布配置的整体连接与验收。测试使用隔离账户和可审查的输入；真实盘中、真实成交及换月验收仍按对应事件进行。
