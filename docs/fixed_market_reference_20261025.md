# QQQ / SPY固定市场参照（2026-10-25）

本研究只补充当前两个完整历史窗口的市场背景。固定QQQ、SPY，各做两本独立买入持有账，合计四账；不选股、不调参、不联网，不改变当前策略或生产账户。它不是新的候选策略，也不是独立样本外验证。

## 运行前固定规则

- 每账初始现金20,000美元，无外部资金流，现金不计利息。早窗2023-12-29收盘建立初始状态，2024-01-02开盘买入，2025-07-30收盘结束；后窗2025-07-31收盘建立状态，2025-08-01开盘买入，2026-07-30收盘结束。
- ETF整数股请求在初始收盘冻结：`floor(20000 / (初始收盘价 × 1.0001))`。只发这一笔买单，下一开盘按原策略同一执行kernel成交：买价为开盘价×1.001，费用为成交额×0.0001，现金不足时按原整数股规则裁减。跳空向下也不扩大已冻结请求。
- 成交后的股票及余款持有至结束，不月度补仓，不强制清仓，不额外收取末日卖出成本。ETF是全额市场参照，不套单股票50%配置上限。
- 使用原始响应的OHLC，不读Adjusted Close，不计普通股息或税务。两只ETF在早窗各有6次、后窗各有4次返回的股息记录，明确排除。若窗口返回分拆或其他非股息事件即停止，不能猜测单位换算。
- 逐日收盘估值，回撤计算包含初始2万美元；年化按初始状态日至末收盘的579日、364日分别折算。
- 四账、零优化、一次运行、最长30分钟；输入或源码SHA变化、缺价、账不平即停止，不自动重试。

## 解释边界

这四账是**不计普通股息的价格收益参照**，不能称为QQQ/SPY含分红再投资总回报。当前策略也排除普通股息，因此会计口径对齐；两类资产实际股息规模不同，不能据此推导税后实际优势。

早窗策略源仍存在`FIXED_CURRENT_OBSERVED_101_SURVIVOR_BIASED`的幸存者偏差，后窗成员完整性也未认证；ETF行情原始来源本身未完成名义价格、完整公司行动及历史真实性认证。价格覆盖齐全、哈希相同只证明固定资料可核对，不能提升这些证据等级。

全额ETF与可能保留现金、集中少数个股的策略风险暴露不同。市场参照提供同期背景，不能单凭收益差认定选股能力或因果超额收益；历史次开盘模型也不代表当前盘中限价实盘成交。
