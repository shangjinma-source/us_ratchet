# 非策略历史成交归档

已结束且用户明确排除的历史交易，可从账户公开成交列表及交易盈亏统计移出。前端使用同一后端结果，不单独隐藏股票代码。

账户数据库旁的 `.trade_scope.json` 文件指定原始成交事件及哈希。校验要求选中的交易构成该证券从起点开始、结束时持仓为零的完整历史；拒绝遗漏买入只隐藏亏损卖出、开放仓位或原始事件变化。同一股票未来的新成交不受影响。

原始流水保留在本地账本归档，现金确认、现金差额审计、账户版本和风险连续性不重写。这里只调整当前策略成交展示范围，不改写历史现金流，也不把历史亏损改为盈利。撤销范围文件可恢复展示。

验证包括未来同股票再次买入、开放仓位拒绝、部分历史拒绝、事件哈希变化拒绝及真实账户副本的现金/其他成交一致性。私人范围文件、数据库和证据不提交 GitHub。
