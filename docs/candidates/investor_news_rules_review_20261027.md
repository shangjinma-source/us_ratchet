# 投资者一手规则：新闻、卖出与再进入（2026-10-27）

结论：值得借鉴的是“先明确持有理由，区分理由失效与短期坏消息，卖出时同时定义重新进入条件”。三种实践不能拼成一个保证保年化、降回撤的万能规则。本轮最值得优先形成完整候选的是**持有理由失效后的退出及事实修复后的再准入**；并非把新闻情绪或两个下降字段直接当交易指令。以下清楚区分原作者经验与本项目拟议转译；不声称这些转译已有收益证据。

## 1. Buffett：经营与管理判断失效，及时纠错

一手证据：Berkshire 2014股东信记录Tesco持仓处理：先因管理层判断转差而部分卖出，随后市场份额、利润率和会计问题相继恶化，最终退出，并承认行动迟缓。这是一笔真实失败及纠错记录，不是统计胜率。原信没有给统一量化阈值或再买回日期。[官方股东信，PDF物理第16–17页、印刷17–18页](https://berkshirehathaway.com/letters/2014ltr.pdf)

可操作转译（本项目设计，不冒称Buffett原规则）：对原策略选中股票，在进入时明确主要业务、增长来源与支撑经营的前提。新事实如果**直接否定原前提**，才进入退出审议。例如核心产品被正式停止销售、已确认财务信息不能继续依赖、主要业务永久失去经营资格；诉讼指控、一般风险段落、季度运送延期不能自动升级为这些事实。最终规则必须事先指定适用事件类别和业务范围，不能事后说“这次很严重”。

动作候选：经可追溯原文确认后，下一可交易时点退出受影响持仓并暂停该股买入；恢复必须有对应正式修复证据，再由原策略重新选入，不能仅因股价反弹解除。若停牌，则记录无法成交，不假设按公告前价格卖出。此动作及恢复机制是待检验候选，不是已批准生产改动。

适用与取舍：可能防范持续经营恶化，却无法保证在跳空前退出；错判可导致永久错过修复行情。当前成长策略的入选理由主要由量化条件给出，不能事后补写漂亮的基本面故事。需要先明确“哪项事实足以推翻继续持有资格”，而非给所有股票建无穷尽估值模型。

## 2. Howard Marks：利空是否改变前瞻价值；卖出后钱去哪里

一手证据：2022《Selling Out》强调单凭涨跌卖出并不充分，要比较未来风险收益与替代机会，并指出择时卖出还需再次判断何时回来。2023《Taking the Temperature》解释其常见卖出理由包括达到目标价格、投资逻辑恶化或发现更好机会；这不是日常新闻驱动的频繁清仓。他也直言所列成功市场判断具有事后选择性质，不能据此推算胜率。[2022官方备忘录](https://www.oaktreecapital.com/insights/memo/selling-out)；[2023官方备忘录](https://www.oaktreecapital.com/insights/memo/taking-the-temperature)

可操作转译：把每条重大利空映射到“暂时推迟、永久损失、无法判断”，记录影响的产品/地区、现金流方向、恢复所需事实。暂时性或不确定性消息首先保留原策略动作；不是强制卖出。真正退出后，比较原策略合格替代股与持有现金两种完整账户路径，不能把卖出收益与其他资金假定最优配置相拼。

再进入：重新检查事实和原策略资格，不要求回到原买价，也不把亏损历史当永久禁入理由。尚未验证前，不覆盖既有20%退出及本月不买回约束。

适用与取舍：更有利于避免因短期利空卖掉长期赢家，但“基本面尚好”不提供最大回撤上限。Marks的长期价值/信用投资经验不能直接证明本成长股轮换策略会受益。相对价值比较需要可信估值；本轮不引入AI自行预测的目标价，也不借此自动加仓摊薄成本。

## 3. O’Neil：价格纪律处理无法及时解释的坏消息

一手证据：O’Neil署名、IBD官方《How to Recognize Sell Signals》给出相对买价7%–8%的亏损控制，承认卖后可能迅速反弹；同时讨论强势末段卖出与市场抛售压力。它是成长股交易体系中的价格纪律，不是“新闻导致基本面恶化”的证明。[官方教育材料，PDF第2–3页](https://shop.investors.com/images/promotional/ClimaxTop_Booklet.pdf)

可操作转译：把价格风控作为独立对照机制，不能等待AI解释新闻才执行既有止损。若将来研究更紧止损，只能固定一个预注册版本，明确相对成本还是月初参考价、次日执行与跳空规则，完整比较再进入和现金去向。原材料未提供本项目所需的统一重新买入算法；不能冒称作者支持“次日买回”或“下月自动买回”。

适用与取舍：可能减小单笔持续亏损，但会增加震荡反复退出与反弹损失。当前20%月度退出与按买价7%–8%是不同测量口径，不能直接替换百分比。O’Neil的买入时机和配套体系也不同；不能把其投资声誉移植成V27改动后的收益保证。

## 本轮建议与停止条件

优先只推进一种候选：**明确定义的持有前提失效→退出/暂停买入→对应正式修复后恢复原策略资格**。选择事件类别时先覆盖整个既定投资范围，而不是挑历史跌得最惨的股票；暂时性供应延迟、跨地区替代需求、业务剥离会计口径变化须作为反例。AI可帮助抽取和对照事实，但不能独自定性“永久损害”。

这条候选仍缺预先固定的适用事件集合与完整时序证据；不在本文件中假装已可回测。若整体资料不能可靠区分首次事实与重复披露、确认与指控、永久损失与延期，就停止这条自动交易候选，而不是追加几个近似字段制造触发。保留不动作组与事实修复组，避免只研究退出而忘记再进入。

用户已授权先做可得样本的局部对照，不以补齐两窗新闻为前置条件。局部验收展示区间收益/回撤与交易现金路径；若要声称长期年化与牛熊稳健性，仍需更广范围的独立对照。投资者案例不代替它。若只有少数样本改善，不能宣布解决最大回撤；年化损失不能被更低回撤自动掩盖。完全有利方可按用户授权采用，存在取舍则展示幅度供用户决定。
