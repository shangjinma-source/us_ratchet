# 当前策略与交易偏好的适配

本轮目标是保留收益能力、减少反复交易和不必要的追高，同时控制大跌风险。现行生产仍是V27；回测改善不等于已上线，也不能用单次错过反弹证明止损一定错误。

| 用户关切 | 当前机制能解释什么 | 本轮候选能否解决 |
|---|---|---|
| 下跌时持续提示卖出，后来又反弹 | 卖出可能来自持仓高于有效目标，也可能来自20%退出；须按该次建议的风险状态区分，不能都称为止损 | 再入场候选保留原卖出规则，不能解决这项适配问题 |
| 未持仓却一直提示补买，随后大跌 | 原目标缺口和现金允许会生成买入；价格模型不等于已读懂财报 | 未持有股票不会因此建立退出锁，故本候选不能防止首次追高；及时新闻风险机制仍需独立经济证据 |
| 退出后跨月又买回，反复交易 | 原月内禁买不等于跨月持续限制 | 候选专门处理此问题：退出日之后完成收盘曾恢复参考价，才解除跨月新增买入限制 |
| 更新现金时操作直观 | 单一现金入口计算当前预算及建议，真实成交另行录入 | 这是工具链路要求，不能用策略回测替代现金到AI的真实操作验收 |

## 已验证的范围

现有数据两段独立窗口的固定机制比较见[回测结果](reentry_repair_result_20261029.md)。两段均改善年化及最大收盘回撤，减少假设成交；早窗仍亏损且回撤高。没有证明该候选能解决全部上述关切，也没有证明新闻AI已提高年化或降低最大回撤。

## 接下来只做有决策价值的工作

1. 当前候选先完成可核验的来源与生产接线；有锁后永久等待买入不是等价实现，不能部署冒充完成。
2. 原卖出规则是否应改变，必须把目标减仓与风险退出分别评估；不因某只股票随后反弹就取消全部风险退出。
3. 新闻AI测试继续以消息实际公开时间、当时可成交时间、明确动作及账户结果为准；事后信息不计入预防大跌能力。经济效果未证明的接口和案例不写成策略成果。
4. 不以减少成交次数单独判优。至少同时报告年化、最大回撤、成交次数和错过上涨的代价；需要牺牲收益的方案仍由用户判断。

本文件不新增参数扫描、不改变生产交易规则，也不把工程测试当成投资收益证明。
