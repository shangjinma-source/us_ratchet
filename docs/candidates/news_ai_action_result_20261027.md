# 五份完整财报：AI动作到真实账户内核的开发实验

结论：已实际完成五次独立 Sol Medium 调用、独立 agent 原文与语义复核、冻结动作、逐日账户回放及独立指标检查。**五例账户差额全部为零，没有新增收益或回撤改善，不批准新闻改变生产交易。** 这次不再要求狭窄的“同口径数字指引下调”，但也没有为了产生交易强迫 AI 清仓。

## 实际执行与结果

每例独立模型上下文，只输入该份原文、来源URL、文本hash和提取空页提示；不传账户、未来行情、旧敏感性结果或其他报告。五例全文合计1,501,503字符，没有主动截断；收据总输入398,589 tokens、输出3,333 tokens，无重复调用。模型历史记忆无法排除。未将SEC接受时间传给模型；它只用于账户执行时钟。

模型提出三个维持、两个暂停新增买入，无EXIT或ABSTAIN。两例通过原句空白折叠校验；三例原始状态为FAILED/QUOTE_NOT_IN_DOCUMENT。独立agent复核确认这三例是PDF抽取中的词内空格或词间空格丢失，保存实际原文位置和上下文，才允许开发回放。**不是用户人工批准，也不是全自动校验通过。** 未修改模型答案或重试；这些诊断继续保留。

## 为什么两项暂停买入也没有改变账户

- **MRNA：原风控已处理。** 原文中的青少年审核延期可能性、跨期交付不确定性支持一个可讨论的暂停新增判断，但不能说永久损害或已证实数字指引下调。11月4日披露在收盘后，首个可用决策为11月5日；当时原20%退出规则已将33股目标降至0，两分支11月8日同卖33股，其后本月持仓与目标均0。AI没有提前卖出，也没有多避免一次损失。
- **NVDA：当时没有加仓需求。** 2023年出口限制涉及历史Data Center地区销售，但管理层同时预计其他地区增长超过抵消，暂停新增属于主观判断，不是整体收入必然下降。首可用决策11月22日，窗口内始终持有7股、原目标7股；暂停买入没有可取消的订单。
- 另外三例的AI维持判断自然复现原策略，不能把零差额算作成功择时。

本轮按事先设计在下一月度选股日之前结束，消除了借用未来基准目标的问题。此前MRNA人工条件实验的+586.12美元来自12月1日少买25股，发生在本轮窗口外，**不得搬来充当本轮AI收益**。零差额也不能证明所有跨月新闻策略均无效。

## 已落地的工程与仍缺的策略

新增研究调用器、因果月内账户回放器、独立指标复核器。原月目标只从共同初态继承；风险状态真实逐日计算；消息必须早于收盘才在该次决策可用，下一开盘执行。保留原风险禁买、0佣金及5bp滑点，所有资金仍在原账户中；未调用月度优化，没有人为锁住释放现金。

这完成的是“原文→AI建议→独立agent审查→冻结动作→账户结果”的**研究链路**。线上仍为V27和新闻研究展示，未上线自动新闻交易，也未证明保持年化并降低最大回撤。原真实成交、月底及新月验收等待条件不变。

## 下一步的入口调整

不再追加本批财报字段、不改变五例窗口寻找正收益，也不重复请求同五份全文。后续若继续，先从**原策略真实存在新增买单的历史决策点**固定样本，再检验当时可得新闻能否改善该笔交易。这是新的机制实验，不能伪装成本轮事前规则。

具体先做无模型成本的动作覆盖核查：按既定基准中的买单日期顺序建立固定小批次，绑定决策前公开材料、明确披露时刻与已有风险状态；资料不足保留缺失，不按后续涨跌选事件。先确认至少有可执行交集，再批准模型批次。若需跨月持有新闻状态，必须定义修复/解除与重新进入；账户分叉后独立计算月目标，不复用未来基准目标。不能把新闻永久锁仓或错失上涨留在回测之外。
