## 原因定位与旧研究去重

当前 `docs/candidates/downside_account_selection_20261105.py:100` 先做当次V27重排，`:102` 的 incumbent 是该新篮子；并非真实旧仓。`data/current_research_capital_decision.py:77`起把原持仓市值加现金转为entered_cash，`:98`调用无prior holdings参数的新现金搜索。`backtest/research_exact_fast_search_observed.py:5`明确不接收旧持仓。旧整数向量可能偶然被搜索命中，但没有强制作为独立候选保留。

然而“新方案评分严格更高才换，否则保留真实持仓”并非全新机制：`data/dynamic_switch_risk_comparison.py:80`构造真实retained，`:82`与新候选同分布评分，`:86`精确比较；`data/dynamic_switch_decision.py:26`起据此选目标。已有动态A经济运行见 `docs/strategy_decisions_20261025.md:16`：L-A 2025-07-31至2026-07-30、E-A 2023-12-29至2025-07-30，0佣金/10bp、每日重搜，与本轮月末D/10股/5bp不同。旧结果不直接回答本轮机制，但不应再把真实持仓同评分包装为从未研究过的方向。

本轮静态结果表明：在已观察路径上，真正障碍不是缺少一个同分优先旧仓的tie-break。12次原样持有与现有50%约束冲突，另6次不满足当前训练下行门槛；其余九次历史评分较低。此为规则与训练目标的描述性诊断，不足以证明换仓造成亏损，也不授权取消50%或下行门槛。
