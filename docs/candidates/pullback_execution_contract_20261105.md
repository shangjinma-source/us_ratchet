# 固定日线价格形态代理：首次两窗账户实验

运行前冻结。不是 Martin 原策略复刻；无历史市值/量能过滤，不以缺量删证券。完整原月合法域，非旧持股或动量十股。窗口、20k、零佣金及5bp单边不利滑点与QQQ一致。早窗D0/D1/D5到账情景全报，后窗D0；仅全EMA9跟踪及3R减半后继续跟踪两个版本，不调参。

前一完整日EMA9>EMA21>EMA50且EMA21上升；收盘突破此前20个完整日最高价建立候选。随后1至5个交易日内，low触及EMA9、close高于EMA9及EMA21、当日高低幅小于突破日，且close高于前日high，形成回踩确认。止损为突破后至确认日最低low。20日/1至5/区间收缩及确认定义均为本项目固定假设；不称真实量缩。没有足够历史OHLC时持现金，完整窗口不裁掉预热。

次开盘只有0<open-stop<=3%open才能入场。排名为前63会话收盘涨幅降序、SID打平，同发行人不重复。每笔计划风险<=前日可交易权益0.5%，分母计买入及stop卖出双边5bp；整数股、最多10只、现金上限、无杠杆、不加仓。未到账权益不可买。9线跟踪止损仅使用前一完整日值且只收紧；缺口穿越按实际开盘不利价格卖，不假设3%硬损失上限。

次开盘已有缺口止损/不再合法域持仓先卖，其现金可供同期开盘买入（模型假设）。新买之后若日low穿越stop当日止损。只用OHLC无法定高低顺序，若stop与3R均可触达统一stop优先；3R按入场含滑点成本+3倍初始每股风险，卖floor(q/2)，余股继续trail。1股无法半卖则不成交。日内卖款不回填更早开盘买单；普通股息和并购款收盘结算、次日可用。无同日止损后再买。

EMA每月以该月事前253日训练close重播（各EMA首n日SMA种子），映射到当月名义单位后接当天真实close；这是固定预热代理，不声称无限历史连续EMA。拆股时旧序列、风险价和股份同步单位转换；未知公司行动或报价缺口阻断，不删股绕过。新日线账户的每日潜在买入与真实已有仓须过原行动门槛。排序/信号完整保存以支持独审。
