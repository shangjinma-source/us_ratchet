# 隔夜持有：有限可行性与固定实验合同

2026-11-05。独立支线，不替代正在准备的 downside 最多十股账户对照。本轮仅读取已有材料并浏览四条查询、五份原文；未运行选股、账户实验或新数据下载。结论：现有日线足以支持条件性隔夜机制诊断，不能证明实际汇丰尾盘/开盘成交可达或保证降低回撤。

## 可借鉴的原始研究与实现

1. Lou、Polk、Skouras，2019，JFE《A tug of war: Overnight versus intraday expected returns》：隔夜与日内收益存在不同延续及反转结构，动量等策略的收益时段不同。这是分解收益的依据，不是本工具股票隔夜必赚的证明。论文将股息、拆股等机械价格变化计入隔夜，且缺失开盘时不能直接删掉该次亏损暴露。[作者原文](https://personal.lse.ac.uk/polk/research/TugOfWar.pdf)
2. NYSE 官方竞价说明：不同上市市场的提交截止不同；NYSE 正常日 MOC/LOC 一般在 15:50 截止，开盘竞价可能晚于 09:30。不能用最终收盘后才得到的信息假装参与同次收盘竞价，也不能将 NYSE 规则直接套用 Nasdaq 股票。[交易所说明](https://www.nyse.com/trade/auctions)
3. QuantConnect/LEAN 已有 MarketOnClose/MarketOnOpen 订单框架，可借鉴订单时点及拒单处理，不必重造策略平台。其官方文档及日线陈旧价格修复说明提醒：日线缓存不能作为盘中实时可成交价，竞价价格模拟不代表真实券商执行。[MOC 文档](https://www.quantconnect.com/docs/v2/writing-algorithms/trading-and-orders/order-types/market-on-close-orders)、[开源订单实现](https://github.com/QuantConnect/Lean/blob/master/Algorithm/QCAlgorithm.Trading.cs)、[官方日线成交修复说明](https://www.quantconnect.com/announcements/20949/closing-the-stale-price-loophole-on-daily-and-hourly-data/p1)。本轮未固定 LEAN commit 或移植代码，也未把该项目作为已验证盈利策略。

## 固定实验：最多两个机制，不搜索阈值

### O1：已知月名单的个股隔夜持有

唯一交易机制：在 t 日收盘买，下一真实会话开盘全卖，白天空仓；每天重复。采用原完整基准保存的月度正目标股票名单，名单仅在决策收盘后的下一会话启用，t 的名单必须在 t-1 收盘或更早已知。若超过十股，按该已知决策日目标名义金额降序、SID 次序打破同分，固定取前十；等额资金分配，空余留现金。该名单来自既有基准财富路径，是外生冻结名单诊断，不能冒称新账户财富反馈后的完整 V27 重跑。

不混入 EMA、风险预算、20%峰值退出或财报择时。设置一条同名单、同等权、同月度换名单的持续持有控制臂，专门分离“只持隔夜”与“换选股”效果；控制臂是对照，不是第三个新机制。QQQ 原持有基准及 V27 另列参考，不把持仓数量/调仓差异归因于隔夜。

### O2：QQQ 隔夜机制诊断

同样收盘买、次开盘全卖，只用 QQQ；与同源 QQQ 持有对照。该臂用来识别市场隔夜溢价能否覆盖交易成本，不作为用户个股策略目标的替代，也不能以其成功掩盖 O1 失败。

## 共同因果和账务约定

1. 两窗分别20,000美元，无新增资金、无杠杆/做空、现金零利息；起始会话日内持现金，首笔最早在首执行会话收盘，最后一会话不开新隔夜仓，避免读取窗外开盘。末日仍计未付股息应收。
2. 首阶段可做收益分解，但必须标“条件性价格诊断”，不输出整数股实盘收益。账户阶段的数量必须在竞价提交前固定：以 t-1 收盘价及当天开盘卖出后已知可用现金算每槽整数股，不能以尚未知 t 收盘价倒算数量。模拟成交按 t 收盘加5bp；若固定数量超过该槽现金则整笔拒绝、该槽留现金，不事后缩股。该拒绝模型只是预登记研究约束，需另核实际券商预检与拒单行为；输出拒单次数及错失敞口。
3. 卖出在下一会话原始开盘减5bp，零佣金为用户当前简化假设，不是频繁隔夜交易永久免费保证；列总周转及超过月25万港币优惠额度的月份（换汇口径不足时仅列美元周转与待核门槛，不伪造历史汇率），未知收费不编造。并列计算0/5/10bp每边的既定执行成本敏感性，并另固定在5bp滑点上叠加5bp每边研究佣金压力及盈亏平衡总成本；非零佣金是压力假设，不是汇丰费率，不以其中最优数值择优。至少每日两次成交，远高于用户原低换手偏好。
4. 除息日在开盘卖出之前按跨夜实际股数确认税前应收，未确认付款不得作为当晚可用资金。QQQ paydate未知可一直保留不可花应收；控制臂采用同口径。拆股需先正确迁移股数/单位，合并交割不能当立即可卖。结算资金能否同日反复使用须明确模型假设，不能凭账本现金等同汇丰可用购买力。
5. 次开盘缺失、停牌或退市不是可删样本；保留未平仓及待估值状态，触发精确数据/行动阻断，不能跳到下一个好价格而不记录期间风险。没有可核执行路径则该窗未完成。
6. 真实 auction 与供应商日 OHLC 不必完全相同。半日市、夏令时及各上市交易所截止须由真实日历和交易所配置控制；先前会话名单满足因果，不等于已证明能在汇丰准时提交成交。不得拿当天财报或盘后消息回填当日收盘买入决定。

## 产出与终止标准

后续若根授权实验，先仅做一次本地数据/名单/行动配对预检（上限10分钟），再一次两窗固定算术/账务（上限10分钟，无选股搜索），独立目录冻结合同/代码/来源。若需新公司行动适配或分钟数据则停止，列精确缺口，不扩成长期抓数工程。

报告两窗及逐年净收益、2022表现、去掉2026的后窗表现、全部成交/周转/拒单、成本盈亏平衡点、隔夜最大单次损失、收盘及开盘权益联合最大回撤、恢复时间、股息应收与现金。联合端点回撤仍不是盘中最大回撤。每日闭市现金会隐藏当晚入仓后的风险，不能仅看开盘平仓现金而漏掉进出场费用与跨夜峰谷。

只有同日期/现金流/成本/股息口径下完整两窗收益及回撤均优于 QQQ，才进入用户核心目标候选讨论；论文结论、无成本隔夜毛收益或仅2026有利都不达标。隔夜集中承担跳空及财报冲击，能接受卖飞不等于能接受无法盘中止损的跳空；此方向值得有限测试，但目前没有盈利或降低回撤结论。
