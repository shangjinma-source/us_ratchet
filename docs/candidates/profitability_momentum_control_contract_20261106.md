# 盈利现金流筛选对动量的影响：固定双臂诊断

运行前冻结，仅两臂，不扫描。问题是同样的252/21动量排序增加已披露NI>0、OCF>0资格条件是否提供增量；不再改变现金流排序、均线、阈值、仓位数或止损参数。

控制臂：沿原月末合法证券域与252/21排序，每月前10个不同issuer，每只十分之一。

筛选臂：同一排序，只接受最近已到达季度截面中同版本年度NI>0、OCF>0且Assets>0的公司，再取前10个不同issuer。季度资料只能取cutoff<=当前决策日期。缺财务资料或身份不确定的证券不算负质量、不赋0；明确标记为可得资料子样本且记录未入选原因。此对照同时包含资料可得性与盈利筛选效应，不能把差异全部归因盈利指标。

两臂共用已修预算的价格诊断：QQQ十月门控、每月调仓、分数股、最多十只、固定20%峰值止损在下一收盘退出、每月峰值重置、同标的跨月待退出保留、单边5bp换手成本且现金不得实质为负。未配置资金留现金；费用求解保持统一，不给一臂不同成本。

仍有同收盘配置偏差、税和完整股息/公司行动账户缺失、历史域与公司事实版本局限、两窗各缺末月，无独立样本外。缺价格不删除股票，只终止对应臂并报告不能比较。显式并购估值代理沿既有规则记录，不能声称实际到账。

两臂都运行，不能直接拿过去不同预算或时点的动量账户当控制组。输出候选资格/排除原因、名单、输入哈希、完整代理权益、费用、持股数及缺口。没有结果前不变规则；失败不调参救回，成功也只进入完整账户验证，不部署。
