# LCID与STX：候选事件原文复核

本轮只核对上一轮两条线索，不看后续收益、不运行模型或经济搜索，不修改生产。

## LCID：数字方向正确，经济含义不能简化

[2021Q3原始10-Q](https://www.sec.gov/Archives/edgar/data/1811210/000162828021023384/lcid-20210930.htm)与[公司财报表格](https://ir.lucidmotors.com/static-files/d634e416-4b02-4038-bd54-2422bb0ac4f4)均显示：季度收入232/334千美元，净亏损524403/161237千美元，分别变化-102000和-363166000美元，与本地候选一致。

原10-Q Note 3说明报表延续Legacy Lucid，不能仅因SPAC合并判为完全不可比。但MD&A明确收入下降来自电池组/供应品销售；当时汽车业务仍在投产阶段。费用还包含与合并条件达成相关的RSU确认。因此“两项同比下降”是会计事实，不等于汽车销量恶化或低于市场预期，也不足以独立证明应禁止2022年1月买入。

[同日更正公告](https://ir.lucidmotors.com/node/7431/pdf)说明添加财务表格。原公告与更正稿的精确首次时间尚未绑定，不能假定最早新闻稿已有全部数值。此次没有原始响应字节存档或机器准入认证，也未完成11月15日至12月31日所有后续披露覆盖核查。

决定：保留该事实线索，但不因这是唯一触发而调整规则、豁免核验或开全窗回测。若未来研究仍使用同比变化，必须在固定规则中处理新业务、一次性费用和披露更新；不能仅为避开此案例事后创造例外。

## STX：同日10-Q晚于收盘

[SEC索引](https://www.sec.gov/Archives/edgar/data/1137789/0001137789-26-000026-index.htm)接受时间为2026-01-30 16:10:41，匹配本地21:10:41Z。[Nasdaq正常时段](https://www.nasdaq.com/market-activity/stock-market-holiday-schedule)为美东09:30—16:00，[2026假日日历](https://nasdaqtrader.com/Trader.aspx?id=Calendar)未列1月30日为假日。该10-Q不能用于1月30日收盘决策。

若沿用“信息可得之后首个交易日收盘决策、次日开盘执行”的研究协议，此申报最早对应2月2日收盘、2月3日开盘，而不是2月2日买入。其候选收入/利润变化均为正，不构成双下降。此前是否已有相同数据的新闻稿仍须另证，SEC接受时间不能冒充最早公告。

## 范围结论

已解决数字与上下文误读、STX同日时间归属两个具体问题。尚未建立完整可执行事件集；不存在可报告的新闻策略收益改善。下一工作应优先补齐可复用的披露覆盖和时刻表，而非继续为单个LCID案例添加交易逻辑。保留全年指引路线停止决定，不重新启动重复搜索。
