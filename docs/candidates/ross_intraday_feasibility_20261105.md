## 免费来源事实

[Alpaca 官方 FAQ](https://docs.alpaca.markets/us/v1.1/docs/market-data-faq) 区分 IEX 单市场和 SIP 全市场；明确历史 SIP 查询 end 至少落后15分钟时无需订阅，但需要账户认证。可先试昨天一个证券一个时段，不能把免费实时 IEX 当全市场成交量。逐笔/报价实际权限、完整性、分页仍须小请求实测，不能据文档宣称数据已拿到。

[SEC 官方 API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces) 免费无密钥，提供 submissions 与财报 facts。可查事件时点以前已发布的原始申报及接受时间；它不是实时新闻全库或逐日 float 数据库，不能把当前聚合事实倒填到历史。

[Databento 定价页](https://databento.com/pricing/) 提供历史数据试用额度，不是永久免费的完整数据源；本轮不注册、不花额度，暂不作为必须依赖。

## 最小可启动路径：先数据冒烟，再固定小样本

1. 若已有合法 Alpaca 认证，先取一个预先指定证券昨天 04:00–10:00 ET 的 SIP trades/quotes，保留分页、条件码、交易所时间及采集时间；最多一个证券日。没有认证则该步骤明确等待数据权限，不用 Yahoo 日线替代。可以从逐笔按交易所时间构建10秒与1分钟线，无法从1分钟反推10秒路径。
2. 数据通过后，事前登记最多5只、连续3个会话的小盘样本。名单须来自样本开始前可见的交易所名册和已申报股数资料；若 float 无法核准，只能命名为“未认证 float 的机制样本”，不能声称测试 Ross 完整筛选。选定后保留无交易、亏损与停牌日，不按当天涨幅事后挑赢家。
3. 此处仅为数据可行性检查，不预设开盘区间突破或2R退出替代用户截图。后续正式草案必须保留首次回调、突破前一根完成K线入场、结构低点止损、日内高点HOD部分止盈等核心；先按截图逐条确定首次回调定义、HOD判定时点、剩余仓位处理。主观盘感、L2承接、逐笔节奏若缺数据须明确未检验，不能偷偷改成容易写的其他机制。未冻结这些语义前不运行经济实验。
4. 逐笔条件码、买卖盘、停牌和限价可成交性决定成交；无报价/点差无法定量的样本拒绝。入场之后才发布的新闻不能解释入场。没有完整新闻时间，只可做技术机制诊断，不可称新闻催化策略验证。

结果必须报告样本覆盖/拒绝数、点差与费用、成交可达性、收益及最差损失；15个证券日仅是流程与机制检验，不能推断牛熊年化、稳定多倍或胜过 QQQ。现有日线回测不构成本支线证据。
