# 新月采集来源审核器

新增 `NativeCaptureReview` 可直接用作 `NativeMonthCaptureReader.review_capture`。服务端固定授权绑定目标、提案、有效期、日历、身份、行动时点、逐证券价格口径和基线资料hash；每次从实际capture收据及原始字节重建审核结果，不复制预制审核结论，也不从adjclose推断拆股口径。

复用实际运输、公告范围及normalizer校验；以精确分数核对基线重叠价格。已授权股息须逐项日期/金额相符，仅审核价格来源，不增加现金或认证券商结算。未知股息或变化拒绝。授权中的未解决权益保留，由风险入口拒绝，不自行清空。

隔离测试 `test_split_native_capture_review_20261105.py` 实际替换reader回调，执行采集、gzip收据、归一化和SQLite风险更新。最终句柄32053终态exit0，1项综合测试28.928秒通过。覆盖已知股息与不同adjclose、未知金额、基线价格改变、未来口径/基线、错误目标/hash以及未解决权益拒绝；拒绝时风险不变。根线程审阅了实际代码与断言并核对文件摘要。

授权资料、行情和账户均为明确合成夹具。此模块验证授权范围及内容一致性，不证明供应商真实性；尚未接入正式配置、完成供应商口径准入或部署。现有V27和真实账户未改变，未来拆股到账不得提前认证。
