# 单事件20交易日局部对照口径

本规范仅定义下一次研究比较；未执行优化或回测。目标是测量一条事前冻结的新闻动作对当时账户的局部影响，**不是证明完整V27策略增益，更不得年化**。

## 1. 同一初始状态及时间

- 从已哈希绑定的完整基准，取事件已公开后第一个可用收盘决策时点；首执行为下一交易日开盘。两分支共享决策前现金、逐证券整数股份、同单位价格、风险峰值/本月禁买状态、原目标、股息应收与其他未到账权益、待执行订单。初值权益按同一收盘价格计算。
- 保存原文hash、公开时间证据、决定时间和交易日历。仅日期无精确时刻时采用统一保守延迟，不按收益选成交日；盘后内容不能用于当天已结束收盘。AI不得见未来行情或本次收益。
- 窗口为首执行日起连续20个实际交易日，含首执行日，末日收盘统一估值。初始收盘另记为day0，不能只取20条净值而漏掉首日损益。缺行情或未知公司行动停止该样本；不可用不足20日悄悄替代完整样本。
- 现有`historical_dividend_next_open_book_research.run_next_open_book`支持initial_cash/initial_shares，但将应收和权益状态初始化为零，**不能直接恢复带未付款股息/分拆权益的中途账户**。此类样本须完整恢复状态或以相同历史前缀重放，不能把应收当现金或丢弃；风险adapter也须恢复，不重置月内峰值。

## 2. 两分支到底比较什么

先冻结一个动作及明确解除时刻。对“禁止新增买入某股票”，研究分支仅将该股票允许目标压到当时实际持仓与原有效目标的较小值，保留原策略卖单；不能误变成清仓。不得提高其他股票目标、挑替代股票或重新搜索。

对照分支遵循同一个局部控制规则、不加新闻动作。建议最小首版把事件时已确定的月度绝对目标冻结20日，原20%退出继续按明确的风险状态规则工作；跨月是否重置峰值也必须在运行前固定并两边一致，不能从后续基准账户偷取不同路径的新月目标。此时名称必须是“事件时目标固定的20日局部对照”，**不是原V27未来20日完整回放**。若目标要求完整V27跨月行为，则必须按两分支自己的资金重做月度决策，这超出零优化局部实验；不能借用基准新月选股冒充等价。

逐日生成订单应按各自实际股份计算目标差，避免复制基准后续卖单造成超卖。禁买解除前每日都生效，不能仅删除首日买单后第二天又补买。两边同费率0、滑点5bp、开盘价格、先卖后买与整数股份。20日末不额外强制平仓，不计假想未发生的退出成本；若另报清算值须单列。

## 3. 现金不足：建议保留原执行分配，不冻结取消预算

采用现有引擎的自然规则：卖出后可用现金C，对剩余买单所需资金D计算`factor=min(1,C/D)`，各单成交`floor(requested_quantity*factor)`。新闻只减少目标/订单，不提高其他目标。取消A买单可能让B从部分成交变成全部成交，这属于真实资金约束的传导，**不能把“不提高目标”误写成“不增加其他实际成交”**。

不建议主结果人为冻结取消预算：现引擎没有该保留金规则，冻结需要定义资金数额、价格与释放时刻，且会引入第二个交易动作。也不能用“原分支本来会成交多少”作为跨分支实时规则。为避免把B的收益冒充A新闻判断能力，应强制披露其他股票成交差额与贡献；若事件动作本身要求资金留现金，那是另一个预先定义的规则，不临时加上。

## 4. 必报结果与归因

| 项目 | 口径 |
|---|---|
| 20日收益 | 每分支`末权益/同一初权益−1`；两者差以百分点、美元各列一项 |
| 最大收盘回撤 | day0至day20各自累计峰值计算；报告两边及差值，绝不称日内最坏回撤 |
| 现金与风险暴露 | 末现金、每日现金/权益均值、现金最大值、股票市值/权益均值；应收单列，不当现金 |
| 成交和摩擦 | 买/卖笔数、成交总额、费用、滑点金额、被取消买单及现金不足未成交数量 |
| 错失上涨/避免损失 | 逐股票报告两分支持仓损益差：末市值差＋卖款差−买款差−费用差＋股息权益差；受影响股票为负即相对错失收益，为正为避免损失，不用事后最高价构造“错失上涨” |
| 间接资金效应 | 单列非新闻股票的额外成交/收益贡献、资金闲置效应；归因总和必须与终值差一致（含应收/公司行动权益） |

输出完整逐日两边账本、订单差异、输入hash与动作记录。单事件结果不代表统计显著、不代表牛熊有效、不拼接重叠窗口、不平均局部回报冒充组合收益。保持年化并降低回撤的采用要求必须另经完整账户对照；本实验只能说明该固定局部动作的后果。

## 5. 最少必要测试

1. 无事件/不相干SID：两账本、订单、权益逐项完全相等；没有“新闻存在即改变配置”。
2. 禁买有已有仓位：保留原卖单，禁止加仓；连续20日不会次日补买；解除只在预定时刻发生。
3. 现金充分：取消A不改变B成交量；目标和实际成交均不超过原目标。
4. 现金不足：设同价10、滑点5bp、费0、现金100.05，A/B各请求10股。基准各成交5股；取消A后B成交10股，现金守恒，B目标仍10。分别报告A直接与B间接贡献。
5. 非整数余款：按比例下取整后的余款不再循环分配；顺序变化不改变比例结果，不能增加某股票补足一股。
6. 已有卖款：两边均先卖后买，同一开盘资金到账假设；报告这属于研究成交假设，不冒称券商结算事实。
7. 日期边界：盘后/周末/节假日、day0和20个执行日、20日不足、窗口跨月策略定义均有确定断言。
8. 恢复状态：非零股息应收、未到账权益、风险峰值、已禁买、拆股坐标不丢失；当前接口不支持的初态显式拒绝。
9. 价值守恒：逐股票及应收贡献与两分支终值差精确相等；末日不伪成交、现金不为负、无超卖。

本次仅阅读现有账本引擎并制定口径，未修改生产、未联网、未运行优化。
