# ROA月包受控采用入口

`scripts.research.adopt_roa_monthly_registration` 默认仅预检；显式 `--execute` 才替换活动配置指针。应从仓库目录使用 `python -m` 调用。入口只接受已绑定的 active 与 registration 路径及 SHA，重新执行正式发布检查，不接受客户端临时拼接配置。

切换限制为月度名单追加，经济规则、账户和执行窗口保持不变。采用前重新构造正式 V34，核验配置来源、活动指针、锁归属和待替换文件字节；原子替换并保留原始字节回滚文件。锁只保护遵守同一协议的发布者，不宣称对任意外部写入具有系统级 CAS。

成功状态是 `ACTIVE_POINTER_SWITCHED_RESTART_VALIDATION_REQUIRED`，仅代表磁盘指针已换。必须另行受控重启并核对运行版本、月份、真实账户及后台任务才能报告部署完成。失败后先核对实际指针；指针已换但回执写入失败时，不盲目再次采用或回滚覆盖后续版本。

验证：`python -m unittest discover -s tests -p test_roa_monthly_adoption.py` 七项隔离测试通过，覆盖预检不切换、精确回滚、旧 active、占用锁、外部指针变化、锁被替换、staged被改，以及切换后回执失败。完整V34构造器使用测试替身；未执行真实生产月包切换，也未安装调度。

调度前另需解决：当前计划固定绑定11月6日 active，发布更新后应重新审核生成；历史来源闭包仍依赖359个 tmp 文件，不能清理后声称可恢复；真实月底新拆股或历史行情修订可能触发拒绝，需要有界核对，不能保证无人干预必然完成。
