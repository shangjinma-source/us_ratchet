# 新闻退出到现金保留：隔离回测接线

新增 `backtest/guidance_frontier_research_v1.py`，将原月度选股 provider、原20%退出风险、新闻禁买、增量卖出归因与新闻现金保留账本接在一起。冻结生产及旧回测模块未改。要求显式 GuidanceNewsRiskAdapter；没有实现安全恢复前拒绝 verified_prefix。

归因由真实分支股份、原风险有效目标与新闻有效目标计算：原本需卖5股、新闻后需卖10股，只保留后5股净所得。原本已需全部卖出的订单不再标新闻保留。配置日期来自冻结 monthly_inputs，与已完成 provider 的目标日期对应。下一次选股接收含保留款的总现金及退出后的实际股份，不复制基准选择。

新增 `backtest/guidance_cash_independent_review_v1.py`，不调用归因实现，分别重算目标差额、卖单净收入、比例、现金释放和每日保留/可用额。篡改净所得或每日保留额会被拒绝。该复核只证明现金及目标归因算术，不认证新闻原文、原风险状态、股票守恒或经济有效性；这些仍须其他独立审核。

测试共22项通过：风险适配器8项、现金kernel10项、接线4项。接线用例仅替换昂贵选择评分，实际 provider、原风险、新闻风险、成交、费用和分红运行真实代码；无新闻时现金、股份、费用、收益、回撤、分红、每日财务账和选择账户输入与原账本一致。有新闻时发生卖出、保留，并将分支账户交给下一配置。另一个空目标WAIT用例仅测试callback与风险/证据审核，不冒称完整公司行动链路验证。

独立审查修复：空目标会令原risk.state=None，等待日不能从此读取月份，改为冻结配置日推导；继续保留未暴露公司行动审核与零订单约束。空事件tuple也已可正常构造适配器。

当前仍未完成：真实历史事件准入集、精确交易日收盘日历绑定、独立全账户/原风险审核、有界完整历史runner及两窗经济对照。本文是执行接线进度，不是上线或收益验收。生产新闻仍为研究展示。
