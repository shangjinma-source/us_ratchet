# 固定阶段式日线代理（运行前冻结）
沿价格代理的候选域、20日突破、1–5日回调、确认、0.5%风险、3%开盘止损距离、整数现金与10股上限。新增唯一机制：入场后保持原始stop，3R前不提升EMA9；首次触及3R卖floor(q/2)，余仓从下一交易日起按前完整bar EMA9只收紧。首次触及当日仍原stop优先。1股不虚构半卖，触3R仅进入profit_stage，partial_taken保持false，次日起trail。两条固定臂为价格形态与额外同源成交量收缩，不扫参数。仍是日线代理，非原分钟策略完整复刻。公司行动实际持仓gate、应收不可花、5bp不利执行保持；更长持有造成的新证据范围缺口须阻断。信号/成交量与正式sourcepins绑定，不使用未来收益挑选。
