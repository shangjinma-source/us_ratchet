# 新闻额外卖出所得的隔离账本实现

新增 `backtest/guidance_cash_next_open_book_research_v1.py`，从现有历史分红账本复制并局部增加保留现金逻辑；旧账本源码与其冻结哈希不变。尚未挂入完整选股 runner，不是经济回测结果或生产发布。

启用时显式传入冻结 `news_allocation_dates`，必须以初始决策日开始且均为窗口内决策交易日。provider 必须报告相同的 `target_decision_date`，以及每笔卖单 `news_sale_fractions`。比例只归因新闻额外卖出部分：原规则应卖5股、新闻增加5股时，合并10股订单仅保留二分之一净所得。这个比例仍需 runner 从原有效目标、新闻目标和实际股份计算，并由独立审核重建，不能任意接受外部数值为已认证事实。

公司行动完成且订单准入和全部卖单归因校验通过后，新配置释放旧保留额。每笔真实模拟 SELL 成交按拆股后成交量、成交价和对应费用累计新闻净所得。取消订单没有保留收入；买入预算使用总现金减保留额，保留额继续计入账户总权益。普通同配置 WAIT 保持原额度且不得下单；换配置 WAIT 不允许解锁。失败准入不清空旧保留额。

10项合成账本测试通过，覆盖跨日保留和新配置释放、费用滑点、混合卖出归因、拆股、公司行动真实取消路径、普通WAIT、错误epoch与新配置准入失败、两笔卖单的全量拆股预校验，以及关闭功能时与原账本逐字段相同。另运行原历史分红账本7项测试通过。测试不是全公司行动路径证明，更不是收益与回撤证据。

剩余：将新闻风险适配器与本账本接线；根据实际原目标计算增量卖出归因；绑定已完成月度选择；从独立成交账重建现金保留并审核；保存或重放完整新闻与现金状态；取得合格事件集后再进行预登记两窗对照。现有模块只能作为这一接线的组成部分，不能宣称新闻策略已可用。
