# ROA候选现金刷新与回测规则接线约束

当前FrozenTargetBuilder每次以最新估值乘权重重新取整，只证明隔离接口可用，尚不等价于月度目标策略。若普通报价刷新也改变目标股数，会额外制造再平衡交易，不能作为本次回测通过后的直接上线实现。

正式接线前需区分事件：

- 普通页面/报价刷新：保持已冻结目标股数，仅更新报价、现金约束下的差额与限价；不得仅因股价变化主动重配。
- 同金额现金确认：允许更新账户revision与建议绑定，但不得凭此触发经济上新的再平衡。
- 实际现金增加或减少：识别其为独立资金事件。是否以权重重配及对现有仓位的处理须进入明确合同和账户情景验证，不能宣称无外部现金流回测已经证明这一规则。
- 月度选择、市场状态变化、个股止损：仅按获准经济合同的信号、生效时点及禁入规则更新目标；普通报价刷新不能提前执行未来信号。
- 真实成交及未成交委托：差额承接、现金确认状态与占款按原账本更新，不把成交造成的余额变化误认作新入金；不预支未成交卖出款。

最低待验收案例：同现金价格变动不改冻结目标；相同金额重复确认不新增再平衡；现金增加/减少各一例；部分成交后只建议剩余差额；新月与市场OFF同时发生时无相反买入。这些是待实现接线要求，不是当前生产功能已通过的声明。

## 11月6日候选接口进展

服务端已支持显式 `target_quantities` 固定目标合同，目标股数随策略合同一同哈希绑定。普通报价和现金确认重新生成建议版本，但保留目标股数；购买力单独限制可买股数。测试覆盖1000美元/100美元报价目标10股，涨至125美元后仍目标10股但只能买8股；增资3000美元仍目标10股；减资500美元只可买4股；真实账本隔离模拟成交4股后要求重新确认现金，再建议剩余6股。

旧权重重配模式仅保留研究兼容，不能默认作为ROA生产模式。此实现仍是隔离候选：尚未接入生产页面、未实现新月与OFF信号优先级接线、未证明资金变化时主动重配更优。当前测试只证明固定目标和现金约束的执行语义；不宣称经济回测或正式上线验收通过。

另已验证服务端收到已冻结防御空目标时的账户承接：如果存在旧买入挂单，返回CANCEL_THEN_RECALCULATE且不产生新建议订单，保留真实占款并要求用户先处理挂单；旧多头target/proposal被拒绝。该测试不代表市场状态判定、新月目标生成与生产自动切换已经接通。

新增roa_signal_target_policy_20261106.py将经审核信号、明确stopped/pending状态和账户可交易权益转为固定整股目标：最多10只、单股最多10%、沿用历史引擎5bp定仓余量；OFF优先清目标、停出禁入、pending不得加仓。两项合成测试覆盖9股取整、pending已有4股上限、停出排除、OFF空目标与未确认现金拒绝。调用者仍须验证真实行情身份/时间、信号时效及风险状态来源；此函数不维护风险状态、不处理pending次CLOSE卖出或实际交易，不是完整上线服务。只能在获准信号事件调用，普通现金/报价刷新继续使用其已冻结数量。
