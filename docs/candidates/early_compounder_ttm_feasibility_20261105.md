# 长期成长支线：两截面TTM与同比本地构造

结论：已有少量同申报版本TTM候选，但尚不能形成已认证的全域质量成长选股输入。此步骤只读本地资料、零下载、零选股、零经济回测；没有改主线、生产或真实账户。

## 全固定域实际覆盖

## 缺口量化

- 2020：21类缺唯一CIK线索；收入/毛利/OCF分别20/47/20类无可匹配已接受持续期间事实，60/34/60类有片段但最新TTM需要跨申报版本桥或缺年度组件。
- 2021：14类缺唯一CIK线索；收入/毛利/OCF分别8/41/7类无可匹配已接受持续期间事实，71/41/72类最新TTM需要跨申报版本桥或缺年度组件。
- 缺直接GrossProfit不等于没有毛利，收入减成本需要另行同期间/概念/版本证明，本次不替代。接受时间未匹配不等于SEC不存在；本地事件库对10-K并不完备。
- 既有五份2021年原文（CHTR/GILD/MNST/REGN/ZS）仍能证明其局部季度或累计数字，但不足以在同一已审原文内组成完整TTM及前一年TTM；完整原文验证率故仍为0，而非否定这些已验证片段。

## 构造与证据

复用`data/ndx_fundamental_normalization.py`的年度/YTD与四季度期间候选识别；新增独立脚本按accession/概念/币种先分组，禁止其默认跨申报拼接，金额用Fraction从原始值精确重算，不使用浮点结果。四季度需逐段连续；累计期不当单季；年度+本期YTD−去年同期间仅当所有组件同accession时保留，TTM起点是去年YTD终点次日。同比仅同accession/同概念可比上一年完整TTM且分母正时计算；负/零分母不输出误导百分比。

实际已有候选包括公司直接披露的TTM OCF、年末10-K年度数及同文件年度+YTD组合。逐事实保存accession、SEC接受时间、概念、单位、起止日、持续天数、精确值与可匹配原文context ID；没有原文匹配时context列表明确为空。候选及同比前期共44个组合经过同accession、无未来披露/期间、精确算术自检。源码及读取证据SHA256全部保留。

单一accession是本次有界安全子集，不是声称合法TTM必须都来自同一文件。一般可以用历史原始年度和后续同口径YTD桥接，但须核对重述、概念变更、前期比较版本及接受时间；当前未具备这条完整证据桥，不能自动拼接后宣称可用。下一最小步骤可针对现有五份财报的年度/对应YTD组件建立版本桥，先统一流程，不据未来赢家选择公司；本次不自动扩展。

脚本：`scripts/research/inventory_compounder_ttm_20261105.py`。证据：`tmp/early_compounder_ttm_20261105/result.json`，包含全部203个截面证券的逐字段实际状态、缺失原因、可用片段与完整候选，不排序、不筛股。单次本地计算约3—6秒。
