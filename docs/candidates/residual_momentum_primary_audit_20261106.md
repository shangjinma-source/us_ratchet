原始资料：[Blitz、Huij、Martens，2011，接受稿](https://repub.eur.nl/pub/22252/ResidualMomentum-2011.pdf)。本次web工具成功读取61页；SSRN入口403，所给Robeco旧PDF重定向主页，后两者未作正文依据。

原文第10–12页：FF3市场超额收益、规模和价值因子；滚动36个月、完整月收益历史；12个月跳过最近月，按同期残差标准差标准化；等权十分位多空组合。第12页说明评分不纳入估计alpha，避免早期观测引入长期反转。24/60月稳健性检验不等于认可一年日频代理。此研究的多空风险改善不能直接推导十只多头组合胜过QQQ或回撤低于30%。

[AQR作者说明](https://www.aqr.com/Insights/Research/Journal-Article/Momentum-Crashes)将市场反弹时既往输家上涨、空头受损列为动量崩溃的重要机制。[Daniel、Moskowitz原论文入口](https://www.nber.org/papers/w20439)同样讨论恐慌后反弹。我们的多头账户没有这一空头腿，不能直接移植其收益/风险结论。

- 253个close生成252个收益：前189个拟合，后63个评分；分别止于dates[189]、始于dates[190]，无区间重叠。QQQ按精确日期索引，缺日记录，不向未来填充。决策日收盘已知后只能用于后续交易。
- 实际使用QQQ单因子价格收益，非市场超额收益/SMB/HML；不跳最近月、仅一年日频、十股多头、原合法域。每项均须声明，不能称原论文复制，也不能宣称行业或全部系统风险中性。
- 实际拟合含截距，评分为 `mean(y-alpha-beta*x)/sd`。代数上等于 `mean(y-beta*x)/sd - alpha/sd`，因此前段高alpha会压低后段排名；这是相对旧基线的表现变化代理。与原论文alpha处理的差别不能隐去，也不应在看完结果后顺手切换两种定义选优。
- 跨证券、QQQ价格必须保持拆股坐标及价格/含息口径一致；当前脚本明确条件价格口径，不能把数据对齐检查当完整公司行动或总收益认证。
