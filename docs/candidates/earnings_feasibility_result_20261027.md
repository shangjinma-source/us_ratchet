# 财报机制：数据基础与真实动作交集

本轮没有把旧“收入利润同比双下降”换成EPS名称重新开策略。三路并行分别核查现存数据、V27代码与操作交集、一手文献；结果改变后续投入方向，但未形成可采用的新闻买卖规则。

## 已实际核验

|范围|结果|边界|
|---|---|---|
|129家发行人原始缓存|114家有直接季度稀释EPS；99家有部分可绑定接受时刻的当前季度记录|不是99家历史完全齐备或全部原文核验通过|
|去重季度观察|14051项，7886项缺少或存在冲突的接受时刻|不同申报重复披露同一财季仍分别保留；不能直接作为历史连续序列|
|已有固定26例|20例同报告季度稀释EPS同比候选：19上升、1下降；6例缺失或冲突|不是分析师预期差，也不是全129家公司或全部历史事件覆盖|
|同26例原策略动作|26/26与原账本决策切片核对一致；首可决策时正买入缺口仅LRCX一例49股，EPS上升|只检查SEC接受后首可决策时刻，不是已认证最早财报发布后的完整市场反应日|
|EPS下降且当时准备买入|0例|不能据此排除持续新闻状态在以后月份改变买单；未检查后续状态有效期|

所有26例均保留，不按涨跌删选。差额用有理数重算，非正上年EPS不生成误导性百分比。没有读取这些新候选的未来收益，没有新优化或经济回测。

## 为什么暂不编码PEAD

V27已核路径是历史收盘价格训练与资金/整数股约束、50%单股封顶、月内20%峰值回撤退出；盈利并不是现有输入。因此盈利数据有可能提供新增信息，但不能由“特征不同”推导“能盈利”。

经典财报后漂移研究讨论预期差消化，而单纯同比EPS符号不是分析师预期差。已查的一手文献同时指出成本侵蚀和现代大盘股漂移衰减。以当前资料，没有充分理由将一个未冻结的盈余意外定义直接写成交易规则，尤其不能把公告跳空计为下一开盘才执行的策略利润。详细来源和适用限制见`earnings_mechanism_review_20261027.md`。

后续继续复用已建的原文、事件时刻、身份和账户执行接口。需要先挑有独立经济依据、公开事实可清楚判断且实际会改变订单的机制；不以补齐全历史为局部试验前提，也不因数据存在就启动参数搜索。当前资料盘点可服务后续机制，不再新建一套重复财报框架。
