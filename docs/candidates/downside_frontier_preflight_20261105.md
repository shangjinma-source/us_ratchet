# 原frontier下行约束：仅机制与数据预检

尚未选择新篮子、回测或改生产。结论：有一个可低成本预检的方向，但不建议在12个情景上直接使用95% CVaR。

## 唯一拟固定规则

1. 每月保持原选择器和候选生成预算。只使用同次 `best_by_k` 保存的篮子，先按原50%规则裁剪整股、去重，包含原篮子。
2. 每篮子按本次决策价格计算证券权重 `w_s=q_s*p_s/可交易权益`；剩余为零收益现金。用已保存253日训练价格生成252个日收益；独立日风险模型 `r_p,t=sum(w_s*r_s,t)`，不是假称这段每日再平衡策略已经被执行。
3. 下行风险采用零收益目标的二阶下偏矩：`D(P)=mean(min(r_p,t,0)^2)`。仅保留 `D(P)<=D(QQQ)`，QQQ用同日原始收盘收益、相同零目标。零收益目标来自既定现金收益0，不增加可调百分比或分位数。
4. 合格篮子继续按原12个21日情景的精确财富乘积排序，保留原同分规则。没有合格篮子则明确现金目标；不临时提高门槛，不新增证券组合搜索，不改原20%退出。

这是基于下行矩思想的**本项目研究假设**，不是已证明收益更高或回撤更低的策略。原frontier按增长目标生成，可能根本不含有竞争力的低风险篮子；全现金频繁出现应算失败信息，不能为追成绩更改生成器。

## 为什么不用12情景的95% CVaR

12个等概率情景的5%尾部只有0.6个期望观察，经验尾均值会几乎完全由最坏一条支配。最坏情景本身也对单条样本敏感，不能把它当稳定未来回撤估计。252日下偏矩使用所有负收益观察，避免先挑一个小尾部分位数；仍受样本短、行情相关和事后选候选影响，不能把252日当252个独立事件。下偏矩忽略亏损排列，并不等于最大回撤约束，也不能保证超越QQQ。

[PyPortfolioOpt官方均值—半方差说明](https://pyportfolioopt.readthedocs.io/en/stable/GeneralEfficientFrontier.html) 支持使用下行波动与收益约束的组合构造思路；[其风险模型源码文档](https://github.com/PyPortfolio/PyPortfolioOpt/blob/main/docs/RiskModels.rst)解释相对目标的半方差。我们不把单股semicovariance矩阵近似偷换成篮子真实负收益截断，拟直接计算每篮子每日收益再截断。[Rockafellar与Uryasev原论文](https://sites.math.washington.edu/~rtr/papers/rtr187-CVaR2.pdf)是CVaR定义的依据；上述0.6样本与可靠性判断属于本项目有限样本分析，非论文对本策略的背书。

静态预检无需新搜索；真正账户回测如改变目标，财富路径变化后仍需按该分支账户运行原选择器。所谓“没有额外候选生成”不等于“整条回测零新增选择”。任何新暴露仍会遇A已识别的股息/公司行动门槛，不因风险过滤豁免。
