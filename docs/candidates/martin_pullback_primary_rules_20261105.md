## 推荐固定日线代理（操作化建议，非声称当事人原版）

供根线程与执行 agent 固定合同使用，尚不构成已授权上线参数：

1. 使用当时可交易证券与因果价格/公司行动口径。趋势为 EMA9>EMA21>EMA50 且 EMA50 高于前一日。EMA用首个完整 N 日均值初始化、随后 alpha=2/(N+1)，至少 50 完整会话，不混 EMA 起算。
2. b 日收盘高于此前 20 个完整交易日最高价，登记一次突破；20 日是我们的固定整理代理。只接受 b 后第 1–5 个会话首次触及 EMA9，且当日收盘仍在 EMA21 上方。回调日 high-low 小于突破日 high-low、成交量小于突破日成交量。该区间/比较规则是研究定义，不是已经核实的 Martin 参数。
3. 回调后 t 日收盘突破 t-1 日最高价才确认，最早 t+1 开盘成交。初始止损为 b+1 至 t 的最低价，确认不得晚于 b+5。这一日线确认明显慢于截图分钟入场，必须单独命名。若同一 bar 同时满足触及与确认，只证明日线收盘条件，不宣称盘中顺序已验证。
4. 实际开盘价加滑点后，要求 0<(入场价-stop)/入场价<=3%；否则跳过。整数股数受 floor(0.005*当时权益/每股初始风险)、可用现金、最多10只及既有单股上限共同限制。不能因止损很窄无限杠杆；不同股票同时出现时按信号日期、股票稳定ID固定排序，是实现约定不是收益优化。
5. 只比较 A 全仓 EMA9 跟踪、B 首次 3R 卖出一半整数股后余仓同跟踪。R固定为原始每股入场风险，不能盈利后重新定义。跟踪为收盘跌破 EMA9、下次开盘卖出；原结构止损保留，止损只能收紧不能放宽。初始止损盘中触发需采用现有因果 OHLC 止损账本，跳空按更坏开盘价执行。止损和3R同日同时触及而无分钟顺序时，用先止损的保守约定并披露。每日仅一套确定优先级，不用最优路径。
6. 缺 volume 不可用 range 缩小冒充量缩；缺市值/AVWAP/分钟数据则报告这些筛选未覆盖。如果为快速检验保留价格形态代理，必须另名并列出遗漏，不能把结果当成截图完整方案的成败。AVWAP本轮不凭事后低点补造；后续可固定“已确认突破日”作为唯一因果锚点，但也是我们的变体，不能本轮顺手加入第三臂。

以上新数值仅用于锁定一个可复现候选，需执行合同明确冻结，不能看结果后更换整理长度或回调天数。既有月度动量 QQQ10月门控、旧20%退出锁与此机制不同，不能未经声明叠加进去。
