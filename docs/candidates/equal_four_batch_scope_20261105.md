1. ALXN 2021-07-21并购：旧 `tmp/alxn_economic_events_20261025/schema_mapping.json` 已有60美元加2.1243 ADS条款，但零碎股净处置款、现金付款及股份交付日期未核，原件明确 `existing_fractional_schema_compatible=false`。早窗冻结assembled没有该事件。原内核存在混合并购基础能力，不等于本事件已经可注入。
