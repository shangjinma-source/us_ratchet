# 唯一ROA/动量融合排序对照（运行前冻结）

仅改变既有盈利资格后的排序：当月合法历史候选，最近已可用季度截面、相同accn年度NI>0/OCF>0/期末Assets>0。资料不可得保持未知、记录排除原因，不当作0或低质量。ROA=NI/期末Assets，动量=既有252/21精确price ratio。

在同一个资格通过的证券截面各算从低到高百分位平均秩：(小于项数+(相同项数+1)/2)/N。两个rank各50%，越大越好，完全同分按SID字典序。按融合降序取前10唯一issuer，不先根据收益挑股票；不足10现金保留。并列按精确Fraction比较，零参数搜索。所有原合法域候选保留审核行。

基线是刚完成原盈利门槛+动量SMA200次open。候选仅一条：同SMA200连续两收盘确认、下一会话真实open切换、同月名单、20%pending下一close、禁补仓/同月止损禁入、5bp预算；复用原价格/财务源，缺实际价格停止，不缩域或猜价格。不再运行EMA/GP或改50%权重。

是盈利能力与价格强度的本地长仓排序代理，非完整QMJ/原ROA因子复现；未加入安全因子。输出两窗/逐年/2022/截至2025、QQQ价格参考、状态与费用/换手。保持财务版本、分数股、同收盘月重配、股息税/真实汇丰费用/公司行动不完整和尾月缺失限制，禁止上线。
