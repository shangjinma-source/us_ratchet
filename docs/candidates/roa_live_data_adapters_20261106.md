# ROA 当前信号、行情与日更新接线

本文件记录实际实现接口，不构成生产激活或真实成交验收。

- `data/roa_current_signal.py` 验证冻结 11 月名单、1,144 个训练依赖及完整来源；只读原始 11/6 信号。
- `data/roa_quote_provider.py` 的 `RoaQuoteProvider` 使用已有严格 Yahoo 分钟解码器。服务器注入身份、已核日历和批准的限价规则。最多四个并发请求，15 秒缓存每次仍重新做 120 秒时效校验；目标和旧持仓可合计最多 20 个 SID。首个真实成交分钟必须完整、OHLC 合法且成交量为正，其 open 与最新 mark 分开。不能用历史收盘替代；失败为 WAIT。
- `data/roa_daily_signal.py` 的 `RoaDailySignalProvider` 接零参信号调用；`refresh_completed()` 是可信后台更新入口。固定 QQQ 原始历史截至 11/5，按已核日历顺序追加完成的日线，保存原始字节、时间与 SHA。缺日不跳过，源历史变化不静默替换。下一交易日必须有紧邻上一交易日信号；12 月等待新的月度名单。
- `frozen_roster()` 仅供已核身份查询，不依赖当天市场信号就绪，也不授权跨月沿用选择。
- `load_completed_close_prices()` 接真实持仓身份和完成收盘日，返回 prices/evidence；真实股数由账户服务提供。近期拆股需要独立公司行动准入，不能暗改股数。漏日重放必须有当日真实持股，不得用今天股数代替昨天。

2026-11-06 实际验证：报价 8 项、日更新与收盘读取 5 项测试通过；真实冻结种子返回 signal_date=2026-11-05、execution_session=2026-11-06、risk_on=true。盘前检查没有网络请求或账户写入。合成下一日测试不能当作未来行情验收。

重要执行边界：分钟校验最早在 09:31 ET 取得完整首分钟，因此 actual open 是目标计算参考，不保证人工按开盘价成交。人工操作窗口和限价规则由正式激活配置决定。严格 intraday 解码器不允许收盘后把过期报价冒充新鲜；收盘观察走独立 completed daily 路径。现有日历对意外休市不作完全覆盖承诺。
