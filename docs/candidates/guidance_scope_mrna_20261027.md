# MRNA：全年总收入规则的口径适配检查

依据冻结基准最早持仓日期排序，MRNA自2021-01-04开始出现。本次仅做公告口径核查，未按亏损大小选公司，未评估公告后股价。

核验两份一手文件：

- [2021-02-25财报公告](https://www.sec.gov/Archives/edgar/data/1682852/000119312521055687/d118084dex991.htm)：2021 Financial Considerations披露已签预购协议对应预计产品销售18.4 billion。它是合同及交付口径，不是公司全年总收入指引；公告还明确区分这类金额与预计全年收入。
- [2021-11-04财报公告](https://www.sec.gov/Archives/edgar/data/1682852/000119312521319285/d603727dex991.htm)：2021 Updated Financial Framework给出预计FY2021产品销售15—18 billion，并说明部分交付推迟至次年。其财务表将产品销售、补助和合作收入分别列示，产品销售不能直接冒充总收入。

结论：不能把18.4到15—18直接标为冻结V1所需的“同口径全年总收入下调”；两份文件也不是已证明相邻版本。该资料具有潜在经济含义，但需要不同且明确的机制假设，不能为取得触发事件而事后改字段名称。此结论只覆盖所审两份公告，不表示MRNA整个年度从未给过其他指引。

本轮网页工具读取了SEC正文；没有新下载完整原始字节，也没有模型调用或经济回测。下一步先完成固定小批次的口径适配检查，再决定是否保留这一窄机制的研究优先级，而不是继续补大量不可能成为该规则输入的资料。
