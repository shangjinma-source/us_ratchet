## 完整账本独审必须分两层

1. 从运行 contract 明确绑定的signal文件、两份原源、adapter、runner及完整month_ends读取并核hash；不猜latest。独立复算EMA和每日market状态，检查首日、相等OFF、E2跨月持续和下一开盘时序。
2. 对每月保存selection用原独立frontier证明核原V27目标及动态资本，不能把最终market零目标交回当作选股目标。
3. 独立按原月目标、历史峰值、20%锁、同SID拆股算出原有效目标。调用原`_review_risk_orders`时仅建立审计副本：target_shares设为独立原有效目标，订单设为该目标与真实持仓的理论差额，移除market附加诊断后由原checker核原峰值、退出锁及价格。这个理论订单仅作原风险层校验，不参与现金或成交重放。
4. 单独核market gate诊断：monthly_ceiling、original_exit_effective、effective、signal_date、mode、market_on都必须等于独立结果。以market状态对原有效目标置零或保留，再核实际订单数量、方向、标价、决策日及下一开盘日。严禁直接拿market目标冒充原风险目标，或让市场恢复解除原锁。
5. 原财务checker仅对真实订单重建整股、滑点、现金限制、股息应收/支付、每日权益和回撤。无暴露identity事件复用严格零暴露证明；有暴露或复杂公司行动必须原gate/专项独审通过，不因市场OFF跳过。
