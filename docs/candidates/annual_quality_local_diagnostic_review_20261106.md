# 年度质量原料：局部诊断可行性独审

结论：**可以开展严格版本约束的局部资料诊断；尚不能据此认证全域PIT、进行正式账户准入或上线。** 不需要把“每份原文尚未重读”解释为所有有限筛查都不可做。本次仅读覆盖报告与两份实际脚本，没有下载、选股或计算收益。

## 代码真正已经约束了什么

`scripts/research/audit_annual_quality_coverage_20261106.py`逐条要求10-K、USD、filed早于截面、期末早于截面、年度330–380天、期末距截面不超过550天。NI/OCF/Assets同accession与期末，NI/OCF同起始日，同字段数值唯一且资产为正。因而并非简单按财年末把后来提交的accession回填过去。

但`certified_pit: 0`是固定输出，`annual_revision_chain_verified=False`也是固定状态；它们表示认证没有完成，而非数据不存在或检测到了所有候选的未来信息。现有69–89家公司同版原料可以用于有限诊断。

当前原文抽检脚本验证部分无segment/scenario、期末相符的inline XBRL值，但没有完成起始日期、unitref实体、transform/continuation、身份和修订链验证，不能称五份完整认证。

## 可立即定义、但本次未执行的局部诊断

1. 固定现有23截面、现有历史候选域、已捕获companyfacts文件hash，不增加收益导向筛选。每行保存SID、ticker、CIK、concept、单位、start/end、accession、各字段filed、acceptance与源hash，不只保存布尔数量。
2. 保留当前版本选择规则：同一期末仅使用截止前已提交的accession，禁止从截止后accession补齐缺字段。输出选择与被拒版本的原因。后来的比较期重述只能在其实际披露后成为新版本，不能覆盖更早截面。
3. 分层展示：A有精确acceptance且早于截止；B仅filed日期严格早于截止；C原文已核字段/未核字段。B不能冒充精确时间认证，但严格前一日期可作为公开日期的保守诊断假设；明确时区、交易时点尚未认证。
4. 只计算描述性比率：NI/期末Assets、OCF/期末Assets、(NI−OCF)/期末Assets，展示覆盖、缺失、极端值与版本冲突。它们不是以平均资产定义的ROA/完整应计质量，也不是完整QMJ。不开启收益排名、选股、组合、阈值或参数搜索。
5. 全域分母保留，缺字段显示缺失而非0；同时报告域内覆盖与不覆盖公司。局部可计算行可以展示分布，但必须标“可得资料子样本”，不宣称全域排名。

## 尚需明确的风险

- **修订链：** 排除10-K/A不等于无修订。后续10-K的比较期可能重述；最新companyfacts还可能发生对同accession的事后数据纠错。冻结当前下载版本只能保证可复现，不能自动保证当时真实可见值。
- **身份域：** 脚本由新闻inventory按ticker映射单一CIK，再使用既有条件历史NDX域；这没有独立证明历史SID/发行人映射及指数成员。退市、ticker复用、外国发行人20-F、迁册与合并均需单列，不能把缺10-K当差质量。
- **字段语义：** 当前可计算原料不覆盖完整利润率、增长、安全维度。直接GrossProfit约四成，不能擅自把收入减任意成本标签拼成等价毛利；NI归属口径、OCF符号、期末资产与平均资产需固定解释。
- **可用性与交易：** acceptance_before_cutoff目前只是日期字符串比较；进一步交易使用需要统一时区和决策时刻。可得数据子样本的选择偏差、财报陈旧度、公司行动账务均不会因资料诊断通过而消失。
- **证据绑定：** 当前pins主要绑定companyfacts/submissions。若落新的诊断产物，还应显式hash绑定候选域文件、身份inventory及脚本本身；不重扫目录寻找原文。

因此可将下一步命名为“年度质量同版本原料诊断”，不是“等待完整全域数据才能做任何工作”，也不是“PIT已经通过”。若将来要测经济效果，应另行冻结缺失规则、身份域、版本可用假设及对照，并明确条件性；本次不批准跳过门槛。
