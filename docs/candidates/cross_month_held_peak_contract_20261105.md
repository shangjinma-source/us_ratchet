# B固定对照：仅连续持仓跨月保留峰值

状态：合同准备，未运行、未改生产。目标分别在2021–2023与2024–2026/7/30同窗口比较原V27及QQQ；年化收益>QQQ且最大收盘回撤<QQQ才满足本轮目标，不拼接账户或只挑较好窗口。

## 去重结论

已查drawdown_mechanism_20261027.md：两窗同SID换月峰值下调33/19次，其中仍持仓24/13次；该文明确只是归因，未做本候选回测。已查reentry_repair_20261029：它在持仓退出意图后设恢复锁，完全退出后仍可保留跨月锁；与B只对连续持仓跨月保峰、完全退出后不沿用峰值不同。已否决恢复月度高点再买入、月内锁仓不重跑。本次有限检索未发现等同B的完整两窗结果；不能宣称证明整个仓库绝无同类实验。

## 唯一变动与状态

1. 原20%阈值不变：已完成收盘价<=峰值*4/5触发，仍次一可执行开盘卖出；不得把当日收盘信号在当日收盘成交。原现金限制、选股排序、50%cap、整数股、费用/5bps滑点和再买入规则不改。
2. 用稳定security_id记录单位收盘峰值，不用持仓总市值或成本价。仅在自然换月初始化风险状态时，若同一持仓生命周期仍有正股数，将新月峰值种子设为max(上期已验证同单位峰值,本次决策收盘价)。所有月内风险处理原样保留。
3. 部分卖出、追加买入、入金出金、目标数量调整不重置既有峰值。判断连续持仓依赖已执行账本，而非target>0或订单意图；尚未成交的清仓不能提前重置。
4. 真正成交后股数归零，结束持仓生命周期并清除跨月携带峰值；原本当月退出锁保持至原规则解除时点，不能因清除峰值允许当月买回。下次合法新建仓使用原V27该月的初始/已回放收盘风险状态，不偷带上一段持仓峰值。不得为此增加等待天数或恢复阈值。
5. 同日卖空仓再买入若内核允许，须按成交序列识别归零，即新生命周期；不能仅以两次日终股数均>0认作连续。
6. 同SID拆股：唯一已验来源证明old/new后，历史峰值与last_close同乘old_shares/new_shares，包含换月当日；不得重复调整已复权价格。加减仓不做此重基。单位、身份或事件缺证则按原准入停止，不能跳过。
7. 现金股息保持原价格风险口径，不新增总回报峰值；并购换SID/分拆新SID不继承老SID峰值，新权益到账与可交易资产继续按原账本规则。不支持的暴露行动沿原阻塞口径。
