# 全年总收入指引路线：有限适配检查结案

## 决定

停止将“同年总收入区间两端同时下调”作为新闻辅助交易的主研究路线，不再为这条规则追加全市场资料搜索、模型调用或执行组件。保留现有代码和证据以供复用。这是数据适配和投入产出决定，不是回测证明该规则无效；新闻辅助交易目标仍未完成，生产不改。

按实际首次持仓排序检查的七家公司，没有形成可用于完整经济对照的事件集。该检查不是整个持仓期的公告普查，不能报告为零负面事件或计算策略命中率。另有 AMD 数值下调实例，但冻结基准在适用期间没有该股目标、持仓或订单，单事件不会改变操作。

| 公司 | 所审资料的限制 |
|---|---|
| MRNA | 合同金额、产品销售并非同口径全年总收入 |
| TSLA | 所审展望为交付量及定性财务描述 |
| ZM | 所审旧财年的结束日在实际持仓前 |
| ALXN、CHTR | 所审持仓前及4月公告未建立未来全年总收入可比对；其他渠道未知 |
| PDD | 所审2020全年公告正文未建立未来年度总收入数值指导；不能外推其他公告没有指导 |
| PTON | 所审FY2021指导为单侧下限，不能伪造上限套入两端比较 |

前五家公司证据见同目录各公司 scope 报告，AMD 见 amd_guidance_source_review_20261027.md。排序和逐日暴露见 guidance_exposure_queue_20261027.md。

## 本轮补齐 PDD / PTON

[PDD 2021-03-17 原公告](https://investor.pddholdings.com/news-releases/news-release-details/pinduoduo-announces-fourth-quarter-and-fiscal-year-2020/)的季度/全年结果、近期事项及前瞻声明均已读取。数字是已实现收入等；正文没有建立未来全年收入范围。未全面检查电话会和随后所有持仓年度，状态是所审文件不适配，不是公司永不提供指引。

[PTON FY2021Q1 股东信](https://www.sec.gov/Archives/edgar/data/1639825/000163982520000174/shareholderletter2021q1.htm)的全年总收入下限为39亿美元；[FY2021Q2 股东信](https://www.sec.gov/Archives/edgar/data/1639825/000163982521000021/shareholderletterfy2021q.htm)提高到40.75亿美元，两者均为“或更多”。这是下限提高，不能产生当前规则的两端下调事件。此轮不扩展单侧区间比较器，不将FY2022下调倒填到2021年4月实际持仓。

本轮为官方网页内容核查，没有新增完整原始响应存档、最早发布时间认证、AI调用或经济回测。

## 下一步必须改变工作方式

现有历史市场预期路径和全年总收入指导路径均不再无限补资料。下一项先检查已有 SEC 季度事实能否支持独立的“已披露基本面恶化”机制，明确它不是低于市场预期。仅检查数据可用性，不先加工程。

一次固定盘点需给出：两窗实际持仓相关直接季度的覆盖率、收入与同口径利润可配对数、完整原文可核验数、公开时间冲突数，以及能影响持仓/目标的事件数。保留缺失，不以零替代，不按未来收益挑事件。先核对原有清单结构和少量原文，若无法从现有材料形成可执行的有限对照，报告缺口并停止该数据路径，不继续搭建空框架。

只有实际样本和发布时间满足条件，才预先固定一个操作规则及完整两窗运行清单。任何采用仍要求同口径年化不降、回撤改善及独立执行复核。法规、战争等其他新闻目前没有验证方案，不把单个财务机制包装为完整新闻能力。目标仍是可解释、可回测且实际影响建议的方案，而非扩大信息列表。
