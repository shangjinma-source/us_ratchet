# 固定市场开盘执行两臂（收益运行前冻结）

共同沿盈利筛选v2的月名单、252/21排序、最多10股每只10%、20%月内峰值pending下一收盘退出、同月止损不买回、5bp费用安全预算；月末重配仍原同收盘乐观代理。无新股筛选或阈值扫描。

A沿SMA200、连续2完成收盘确认；B仅以EMA20替代SMA200、同样2收盘确认。EMA20用首20日简单平均初始化，之后alpha=2/21递推，使用同一QQQ起始原始序列。状态继承，初始账户现金。历史预热与计算截至信号D，转换在下一交易日D+1开盘执行，不在D收盘交易。先A后B。

实际D+1流程：持仓从前收盘计隔夜到开盘；市场OFF先卖清，故不再承担当日开盘后股价变化，也优先取消这些已清股票的pending个股退出；ON按当前月冻结名单与可用开盘权益、费用安全base恢复（排除同月已止损），pending目标不超过原开盘值；之后仅实际持仓计open→close，既有pending仍到close卖出，新20%close触发等下一会话。开盘新建仓峰值从开盘起计，当日close可触发pending。

执行OHLC来自既有冻结execution_inputs；同日open/close比值用于将训练价格的日收益分成隔夜与日内，因为同比例单位缩放抵消。所有实际转换日所需SID必须有真实正open/close，缺失即停止，禁止用close假代open；SMCI只允许已核新旧1:10精确桥。潜在名单预检不因缺数据删股。QQQ日期交集逐会话完整，重叠源一致。

两个窗口仍独立20k和既有缺尾月；QQQ价格参考同锚点/末日、首建仓5bp，分红再投参考另列。输出各窗/2022/2024–25/2026、转换日期费用/暴露/缺口。不声称真实账户/PIT/税后/公司行动完整；分数股与同收盘月目标偏差保留。
