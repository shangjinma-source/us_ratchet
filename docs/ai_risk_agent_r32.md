# AI 风险复核 Agent（R32）

专用 Agent 使用 `gpt-6.1-sol`、medium。后端的新闻预分析和持仓复核两条入口实际加载 `skills/us-equity-news-risk/SOUL.md` 与 `SKILL.md`，结果展示在「今日买卖建议」的 AI 风险方案中。Codex 本机也安装了同名 Skill，可显式调用。

## 如何判断

先读当前公开原文，结合已认证的旧财报背景，区分新事实、推断、反证和未知。重点检查经营中断、收入与利润质量、现金和融资压力，以及政策事件对发行人的具体暴露。允许提出暂停买入、减少买入、减仓或退出；证据不足应弃权，不能为证明有用而强行卖出。

用户可以接受错过部分上涨以降低重大下跌风险，但不构成无条件牺牲长期收益的规则。技能是可审查、可版本化的工作方法，不是经过训练而保证有效的预测模型。

## 当前操作边界

正式策略仍为 V27。AI 方案目前是研究预览，不自动替换正式挂单或执行交易。新账户版本、目标、原风险规则、消息时效、整数股、报价和可用现金仍由后端复核。20%退出保护不解除，未成交卖款不提前用于买入。

技能内容固定哈希进入部署、模型缓存、调用回执和意见身份；文件异常拒绝调用，版本不符的旧意见失效。模型只读取两份核心文件，参考材料中的历史结果不进入提示词。改变技能必须重新验证并部署。

## 已验证与未验证

R32 的接入、缓存失效、背景兼容和异常拒绝已通过测试；使用一个明确标识的合成事件完成了一次真实模型调用，输出了带原文证据及缓解因素的风险意见。随后在隔离账户中将该实际回答贯穿真实复核链路：7股保留一半映射为目标3股、候选卖出4股；现金不提前增加，开盘前或账户版本变动时拒绝。测试注入了合成时钟、行情及全文恢复，并非实盘验收。这仅证明调用与账户计算链路，不是收益或回撤验证。

现有历史研究仍是开发案例，包含零增益与未避开下跌的结果。尚未证明长期年化保持或提高，也未证明牛熊全周期最大回撤下降。后续研究须冻结当时资料、时间和动作规则，并保留失误与错失上涨，不能只积累成功案例。
