# 已有持仓的资金预览：候选接口

状态：2026-11-14 候选代码，未部署，前端尚未接入。

`POST /api/strategy-roa/funding-preview` 可选接受 `broker_holdings`，包含 `account_revision` 和 `positions`。每行必须提供 `broker`（HSBC 或 USMART）、`security_id`、正整数 `quantity`。版本必须匹配当前账户，两家持仓合计必须与正式账户逐证券相等，同券商同证券不得重复。

该输入只用于本次只读预览，不持久化、不转移股票、不写现金。没有归属资料时仍明确等待核对，不从现金余额推断股票归属。

本候选只放行已有持仓下的新增买入预算；存在挂单或卖出建议仍不支持。未来卖出必须按持仓所在券商分配，不能提前使用未成交卖款。当前仍只支持汇丰免费额度已用尽的情形，不能宣称完整双券商分配已经上线。

验证：9 项预算预览测试、6 项 HTTP 测试通过。HTTP 编排测试模拟建议校验结果，不能替代真实行情、页面或转账到账验收。
