# 双券商资金规划进度

目前实现：只读首次转账预算。尚未接入正式前端，也不属于分券商订单执行系统。

- 使用现有 ROA GET-only 验收器读取账户、活动配置、建议，再读取账户确认未变化。
- 只有 API 建议有效且当前无持仓、无挂单时生成首次资金迁移预览。
- 两家券商确认现金之和必须等于工具可用现金，避免重复计算购买力。
- 当前分支仅适用于已确认汇丰本月免费额度耗尽；额度尚余时不直接套用此分配。
- 盈立使用个人标准账户收费，不采用优惠计划。其他费用及转账费用必须作为明确预算输入。
- 计划转账不增加盈立实际可用现金，不写账户、不下单；到账后必须重新获取建议。
- 输出绑定账户版本、提案、目标、报价失效时间。过期后仅可作为历史预算查看。

入口：`scripts.preview_broker_transfer`。输出目录必须为新的本地私有目录；账户证据不得提交 GitHub。

验证：15 项单元测试通过；2026-11-14 北京时间 00:37 对本机 8010 完成真实 GET-only 预览，API 验证通过，前后账户一致。此验证不代表页面集成或真实转账通过。

待完成：前端资金规划展示、免费额度优先分配、到账确认与分券商持仓/委托归属、内部划转不计入外部入金。正式策略选择与目标数量不因转账预览改变。
