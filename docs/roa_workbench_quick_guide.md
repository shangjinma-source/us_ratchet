# ROA工作台简易说明

2026-11-06：新版已部署，执行窗口尚未配置；目前是计划展示，不能把待开盘名单当作挂单指令。最新状态见[部署记录](current_roa_deployment_20261106.md)。

## 每次如何操作

1. 打开本机 `http://127.0.0.1:8010/`。
2. 把汇丰最新可用美元现金的总额填入“当前可用现金 USD”，点击“更新现金并查看建议”。入金、换汇、取用资金、卖款到账均填最新总额，不填变化差额。
3. 只有建议已开放执行、报价有效且给出明确股数与限价时，才有可供你在券商手动操作的建议。等待信号、等待报价、待确认现金或错过时段均不是挂单指令；工具不自动下单。
4. 成交后按实际成交录入，部分成交只录已成交数量，再确认券商最新可用现金。仅刷新建议不会凭空生成成交；未到账卖款不会预先当作可买资金。
5. 已有未成交委托要如实保留并核对，不能把“已提交”当成“已成交”。完成后的剩余建议按实际持仓更新。

## 策略如何判断

盈利质量与中期动量各占排名一半，最多十只、每只目标10%。QQQ相对200日均线连续两次收盘确认风险状态，在下一开盘切换股票或现金；个股月内峰值回落20%触发下一交易日收盘退出，退出后本月不重新买入。现金刷新沿用已确认目标，不因余额改变反复重新选股。

人工限价挂单与回测开盘/收盘成交存在差异。开盘和收盘操作窗口仍待确认；不承诺未来最大回撤一定不超过30%。

## 当前边界

- 月末准备程序会检查数据、生成名单并冻结输入；新月名单需通过正式配置采用。没有新月份有效数据时停止建议，不用旧名单冒充。
- 牛熊切换、部分成交与换月接线已通过临时账户测试；这不是用户真实成交或未来新月实盘验收。
- 原新闻后台仍运行，但尚不能声称AI已经修正ROA挂单或带来已证明的收益改善。
- 账户数据库与本地证据不随GitHub源码上传；不要用空账本覆盖已有账户。
