# 为什么 20% 个股退出仍会出现 71.77% 账户回撤

结论：20%规则控制的是单只股票**当月**的收盘峰值退出信号，不是账户自历史高点的亏损上限。集中持股、下月重买及峰值重置，使多段损失可以累积；次开盘执行还存在信号后的价格变化。本次只读归因，未做优化、回测或生产修改。

早窗已有完整归因，本次校对复用其结论，仅补齐后一完整账户与跨月峰值审计。两段各自从20,000美元开始，不能拼接。

## 最清楚的跨月重复暴露实例

APP 在后窗最大回撤期间：

- 2025-02-25触发退出，2/26实际卖出32股；3/3重新买33股。
- 3/6再次触发退出，3/7卖出33股；这一重买段价格交易损益约 −$3,115.14。
- 4/1再买35股，4/4触发退出，4/7卖出；这一重买段约 −$2,123.59。
- 2/28与3/31的月度风险峰值分别重置为前月峰值的约63.9%和76.5%；当时原仓已退出，下一月允许重新开始。

这说明制度上的风险记忆会在换月后重启；不等于“禁止重买就能赚回$5,238.73”。改变买回会改变现金、其他股票及全部后续选择。早窗已有盈利的MRNA重买段约+$7,100，禁买也可能错过收益。

## 是否值得立即再跑一个机制

**当前没有足够证据支持再开一轮新的高价值参数实验。** 看似直接的“延长退出冷却/跨月保留旧峰值”与已做的恢复月度高点再买入、月内锁仓及换仓研究有重叠；不能只因APP这一段亏损就选更长冷却期。固定QQQ十月趋势已完整对照：后窗年化下降18.85个百分点，仅换来回撤下降5.64个百分点，已不采用、停止调规则。

有证据支持的下一步只是：如未来重新立项，先核对既有“恢复高点再买入”规则是否已覆盖**跨月仍保留退出记忆**，若完全相同则直接排除重复；若确有不同，也须先登记唯一规则与两窗收益约束，不从本次亏损日期拟合等待天数。本次不据此新增候选或给出预期收益。

因此“保持年化并降低最大回撤”仍未达成，不能报告为只剩开盘验收。新闻AI的解释也不能被当作解决这一数学策略缺口的证据。
