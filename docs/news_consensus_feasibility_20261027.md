# 历史市场预期：有限免费来源核查

结论：本轮检查的来源没有取得可直接用于两段窗口的、公告前冻结的同口径 EPS 与收入预期。本轮结束这批来源的获取尝试，不启动双 surprise 收益回测，不把同比下降改名为市场预期落空。这个结论只覆盖已查来源，不是证明世界上不存在免费资料。

| 已查一手来源 | 实际可确认 | 当前不准入原因 |
|---|---|---|
| [Alpha Vantage 文档](https://www.alphavantage.co/documentation/) | EARNINGS 介绍季度 EPS 及预期；EARNINGS_ESTIMATES 介绍 EPS、收入预期及修订历史。两个公开 IBM demo 实际都仅返回需要申请 key 的提示。 | 没有取得可检验的历史记录，不能证明公告前快照、版本和覆盖。未申请账户或读取其他账户凭据。不能因字段称 revision history 就自行认定满足历史时点要求。 |
| [Estimize 数据字典](https://estimize.com/data_dictionary) | 描述逐日一致预期和时间戳版本；API 试用描述为一年历史，完整历史另有机构/学术渠道。 | 公开文档不是已获得的数据；一年试用不能覆盖冻结的两个窗口。未申请试用、联系销售或购买服务。 |
| [Earnings Whispers API](https://www.earningswhispers.com/data-api) | 访问能力随会员层级变化；页面列明五年历史及 watchlist/universe 权限。 | 未取得有授权的历史样本，未证明预期形成时点；会员公开说明不能替代真实可用记录。 |
| [开源 earnings_surprise_analyzer](https://github.com/leeyawnnn/earnings_surprise_analyzer/blob/main/README.md) | 作者明确免费一致预期是当前快照，不是带修订历史的时点预期。 | 不直接复用其 consensus 作主信号。也不执行其代码后把其收益当本工具结果。 |
| [FinCall-Surprise](https://arxiv.org/abs/2510.03965) | 论文描述 2019—2021 电话会研究资料。 | 时间覆盖不足，摘要不能证明标签满足本候选的公告前预期要求。 |

上述提供商描述不构成推荐或收益证据。完整预期资料即使取得，仍需单位、GAAP/调整后口径、拆股、首次公告时间及修订检查。

## 接下来的不同机制

转向检查公司自己公告的同一期间数值指引修订，直接比较相邻原始文件，避免依赖未取得的市场预期。它是不同的研究假设，不能借用双 surprise 文献的收益结论。

先只做两家公司原始文件可行性与确定性事实比较：同发行人、期间、指标、币种/单位和会计口径；后次区间上下端均低于前次才记明确下调候选。撤销、不可比或缺值记未知，不能由模型猜成卖出。AI 只抽取附原句与数值的事实，交易影响与经济验证另设门槛。

不根据这两个样本的后续股价判断机制有效，不启用生产交易，也不将两个样本视为全证券覆盖。可行后再冻结一次有界对照；不可行则记录具体缺口，避免无休止搜集网页。
