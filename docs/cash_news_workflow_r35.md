# R35：现金入口联动 AI 复核

2026-10-29 已部署。

## 操作

点击“更新现金并查看建议”：先保存现金并刷新 V27 建议；取得有效建议后异步发起既有 AI 新闻复核。独立 AI 按钮移除，新事件发现开关位于主按钮右侧，状态集中在下面。AI 处理期间已生成的建议可见。页面加载及顶部普通刷新不自动触发按需模型调用。

保存失败、WAIT 或绑定无效时不启动 AI；已有复核在途时不重复发起。既有预算、账户/目标绑定、失效与研究预览边界保留，不自动交易。

## 性能与限制

只缓存完整月度目标字节对应的确定性提案计算，容量一项。每次仍读取 SQLite 并逐字比对；返回独立对象。目标任一内容改变会重新计算，数据库篡改会拒绝。账户、风险、实时行情以及全部来源校验未缓存。

- 真实目标 28 次只读对照：旧计算 6.754 秒，新计算 0.723 秒；56 次输出字节全部一致。
- 实际 preview：发布前单次 35.724 秒；上线后与页面同时刷新单次 39.382 秒；独立复测 30.419 秒。均通过 API 金融一致性检查。单次测量不是稳定延迟保证；整体仍为几十秒，未宣称秒开。
- 更深层源码校验重复读取涉及历史版本依赖，本次没有迁移，也没有移除校验。

## 验证

3 项缓存防错测试、9 项原提案/接口回归通过。5 组主按钮、AI 衔接、现金/成交/目标变化、迟到响应及资本锁测试通过；新闻独立复核、事件开关与监控显示回归通过。

实际浏览器确认主按钮及右侧开关位置、独立 AI 按钮消失、建议正常显示。真实接口复测保持账户与目标前后一致；现金提交到 AI 的联动采用隔离模拟测试，没有为验收写入真实现金或制造成交。
