# 回撤研究第二轮：机制筛选与有限验证边界

2026-10-25。用户新增要求：全面借鉴成熟投资研究，保持或提高年化不能舍弃；若存在收益下降但回撤明显改善的方案，先展示交换幅度，由用户决定，不能自动替换生产。当前生产基准为V27。本文件是首轮文献、代码与既有结果复核，不是新回测成绩或上线承诺。

## 已知问题与研究目标

V27早窗年化135.6532%、最大收盘回撤37.7911%；后窗年化248.7669%、最大收盘回撤15.1533%。两窗独立起算，存在选池偏差与重复查看样本限制。新候选必须与V27比较，不能只战胜旧版205.3861%的后窗年化便称为进步。

已有账本的峰谷损益分解：早窗APP贡献约31.34个百分点损失，MSTR约4.03、RKLB约2.42；后窗APP约9.26、PLTR约5.89。V27两个最坏回撤区间在其重排生效前，归因可解释当前基准的这两段损失，但不证明特定规则能避免它们。

需要分别考虑：单股跳空及集中暴露、相关股票同时下跌、跨月退出后再次买入、风险降低后如何恢复仓位，以及12个历史月度情景的估计误差。波动小不等于最大回撤小，历史最大回撤小也不等于未来存在损失上限。

## 文献与适配判断

以下适配优先级是针对本工具的判断，不是论文结论；没有把期货、多空因子或机构组合的收益直接搬给美股个股账户。

| 方法 | 一手研究及机制 | 对本工具的意义与限制 | 本轮处理 |
|---|---|---|---|
| 波动管理 | Moreira–Muir研究高波动时降低风险暴露；Cederburg等发现实时样本外投资不普遍胜过原组合 | 有机会控制高风险时期仓位，也会滞后减仓、错过反弹；不能用全样本波动归一化制造前瞻优势 | 优先审查一个无杠杆固定规则；必须配简单现金缩放对照 |
| 稳健增长配置 | Sun–Boyd对一组可能概率分布中的最差对数增长优化 | 对应当前仅12个情景等权的脆弱性；不确定性集合本身不能用测试收益选出来 | 优先做保存候选的训练稳定性诊断，未满足条件前不发起完整经济回测 |
| 趋势过滤 | Moskowitz–Ooi–Pedersen主要研究多资产期货的时间序列动量 | 持续下跌中可能有用，震荡及急反弹可能反复止损；当前个股多头不能照搬期货多空结果 | 已有SMA20/半仓/弱势退出旧研究，先利用已有反证，不改均线长度重跑网格 |
| 分散配置与相关性控制 | 经济机制是减少同一风险来源的暴露；增加股票数量本身不足以证明分散 | 有助处理同跌，但历史相关性会变；等权、行业约束也可能削弱赢家贡献 | 与候选稳定性一起检查持仓风险集中；不预设“必须持有N只” |
| 基本面质量 | Asness–Frazzini–Pedersen的QMJ研究盈利、增长等质量维度，多空组合证据 | 可能减少脆弱企业暴露；需要当时已披露且保留历史版本的数据 | 缺少点时财报前只做可行性判断，不把今日指标倒填历史 |
| 组合止损/退出后恢复 | Kaminski–Lo讨论止损价值取决于过程与采样条件；不能认为止损天然增加收益 | 当前跨月重新买入是明确风险点，但已失败的恢复峰值候选不应换名重跑；必须同时定义再进入 | 保留独立机制比较，首批不增加第二套退出阈值 |
| 风险约束Kelly | Busseti–Ryu–Boyd对固定比例、独立同分布设定给出初始财富下穿概率约束 | 不等于运行高点最大回撤；也不能在有限、偏差历史样本上保证实盘回撤 | 用作风险定义参考，不直接照搬约束宣称安全上限 |
| 保护性看跌期权 | Cboe PPUT示范股票指数与月度保护性看跌组合 | 权利金、期限、基差和执行复杂度不能忽略；用户目前只授权股票工作流 | 理论对照，不接入期权、不假设券商权限或零成本保险 |

## 优先落地的两条研究线

独立审查同意仅保留以下两条。实际顺序先完成训练稳定性诊断，再决定波动预算是否具备明确输入及参数依据；两条不叠加。等暴露比较只能使用事前固定或过去数据形成的暴露规则，事后平均暴露匹配仅作解释性归因，不作为可执行策略成绩。

### 1. 无杠杆风险预算：先确认是择时改善还是仅仅少买股票

代码已有`backtest/current_quantity_v2_risk_overlays.py::volatility20_target20`，使用20个收益观测、252日年化、20%波动目标，月度调整并固定数量到下月。该20%是既有研究参数，不是用户确认的风险容忍度；函数对股票篮子归一化权重估计波动，不等于含现金全账户20%波动保证。

不直接启用此旧函数。先核对旧经济结果、V27输入和估值单位兼容性、候选是否实质重复。如果允许进入固定对照，必须把现金占比、整数股、公司行动、退出优先级、风险恢复与下一开盘执行全部记入新分支。不得把日度调整与月度调整混称同一规则。

应增加一个事前固定的简单降仓基准，以区分主动波动管理与少承担风险。不得用候选全窗实现后的平均暴露反推控制组仓位；也不预先宣称50%就是最佳现金比例。参数和控制组必须在读取新经济结果前冻结。

### 2. 训练情景稳定性：尽量保留增长能力，减少对少数历史月份的依赖

当前`core/saved_monthly_frontier_proposal.py`在同次保存的候选中比较12个情景财富乘积。可先只读分析：删除任一情景后，原赢家排名、集中度与现金是否大幅变化；最差情景是否由同一风险来源主导。所有计算只使用决策当时已存在的情景。

删除情景检查是脆弱性诊断，不是对未来概率的估计，不构成独立验证，也不能从12种删法挑回测最好的一种上线。诊断没有识别有意义的稳定性问题，或只能借助未来结果决定不确定性范围，则本线停止。若进入候选设计，只允许一个事先定义的不确定性规则，并与原V27评分并列记录，不能继续扩大搜索预算。

## 有限研究清单与停止条件

1. 首批最多两个机制方向，先做来源、重复实验和输入可行性复核；不同时叠加趋势、波动、质量与止损，以免无法解释差额。
2. 经济运行前提交完整清单：规则、参数来源、分支数、输入及代码哈希、窗口、费用、执行模型、最长时间和失败后处理。首批经济计算总上限30分钟；预计超出时先缩小可回答问题，不能静默延长到数小时。
3. 对照使用V27两窗，保留原研究1bp佣金/10bp滑点仅用于同口径，不称为汇丰实际收费。用户暂不考虑佣金不代表滑点及跳空为零。
4. 资金路径分歧后必须用各自资金重新选股；不能按旧数量乘一个比例就声称完整策略收益。单纯保存路径压力测试单独标注，不混入正式排名。
5. 参数不扫网格，失败不自动换阈值。技术失败保留原结果，先解释；修复并重试必须仍在冻结预算内，不能把不完整窗口报为完成。
6. 首选每个完整窗口年化不低于V27、最大回撤不恶化且至少一项改善的候选。年化降低但回撤改善的只进入用户权衡表，不自动淘汰，也不自动部署；收益和回撤都更差的停止。
7. 同时列出区间收益、年化、最大回撤、回撤持续与恢复时间、成交数/单月最多次数、现金占比、最差日/月与跳空损失。现金流用单位净值或明确流量调整，不能把入金当盈利、提款当回撤。
8. 两个已看过窗口不能重新命名为独立样本外。研究结论区分历史机制筛选、真正未参与选择的数据验证、纸面前瞻和真实账户验收。数据欠缺不扩大为无限修历史工程。
9. 不以研究为由改动V27、真实账户或盘中/月末验收任务。即使历史结果更好，先报告适用限制与操作代价，由用户决定是否采用。
