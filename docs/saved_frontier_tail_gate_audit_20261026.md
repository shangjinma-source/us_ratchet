# 固定 0.80 尾部门槛：零搜索纯函数

`backtest/saved_frontier_tail_gate_audit.py` 的 `audit(raw_selection)` 只接同次保存的原选股对象，先复用现 cap50 rerank，再调用独立 reviewer 校验账户绑定、日期、原 frontier、现金、费用、原赢家和确定性并列。原赢家指当前 V27 cap50 后重排赢家，不是未裁剪生成器赢家。

固定十二情景、门槛 4/5；原赢家通过则逐数量保持。否则仅在原已保存、cap50 去重后的通过篮子中按原增长乘积、较低名义投入、字典序择优；保存的 k=0 现金参与排名。没有通过的持股篮子则现金。沿用初始买入费用及残余现金，未到账权益不另行加入预算，不加卖出或终端平仓费用。输出精确情景财富倍数、最差倍数、增长摘要、现金、选中数量和改变原因，绑定原选择 SHA。

五项合成测试通过：0.80 精确边界、费用使边界失效并改用既存候选、无通过篮子全现金、账户和费用证据篡改拒绝、非十二情景拒绝。未读取任何当前连续基准候选运行审计，未新搜索、未执行经济对照、未接生产或分支 runner。

这只是可行性审计接口，不证明经济优胜，不保证回撤不超过20%。现有日期验证只验证保存的成熟情景；不声称重新从原行情认证每段恰为21日，其仍依赖冻结上游输入审核。完整基准结束前不调用当前数据，不调整门槛。
