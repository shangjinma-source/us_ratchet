# 组合波动研究：旧实验区分与输入预检

2026-10-25。V27仍为生产基准，本轮未运行经济回测或修改生产。先排除重复研究，并确认相对波动候选的输入是否可用。

## 不能直接复用的旧成绩

`tmp/daily_risk_windows_20261016_v1/report.json`明确标记为同一历史路径的22个重叠切片，不是22个独立样本或独立初始资金实验。旧R1使用20个日收益、固定20%年化波动目标、月度冻结；22个切片均降低回撤，只有3个提高区间收益。它使用旧股票池/基线、零模型费用及下一开盘成交，不是V27结果。

因此不重跑“固定20%目标”来寻找支持结论，也不能把22/22解释为降低未来回撤的概率。其主要教训是：降仓容易降低损失幅度，但可能明显牺牲用户重视的增长。

## 尚未完成的独立问题

已有计划中的B是短期与长期风险之比：`min(1, 长期方差 / 短期方差)`，拟用21与252个已完成日收益。它无需预设账户接受20%波动，也不允许杠杆，但仍不是论文原样复制，更不是收益保证。

与旧R1的区别是相对风险状态，而非固定绝对波动目标。是否值得运行，需要先确认输入、频率、零方差、取整和恢复规则；不能只换名字重跑同一缩仓。正式试验前需记录其与旧R1在相同训练输入上的动作差异，该动作诊断不等同于新策略回测。

## 有限的下一步与停止条件

先做一次31个月度输入的来源映射与日期/单位预检，不做每日扫描，不下载新的大批历史数据。只从已绑定的原始行情及公司行动构造决策当日单位的253个收盘价；训练日期必须不晚于决策日，边界缺失、身份或公司行动无法核对时列明月份和原因。

这是月度频率可行性预检，不提前决定日度波动策略。当前组合权重投影过去收益必须标为风险估计，不能称为账户真实历史；现金与未到账权益也不能混作股票权重。若31个月无法在现有来源范围内通过，则收敛报告数据缺口，不扩展为无止尽数据修复。

通过输入预检后，才冻结一个相对风险规则及事前固定的简单现金对照，报告完整运行清单。基准必须是V27，资金路径分歧后独立重选；正式经济计算仍受第二轮总30分钟上限约束，不自动追加参数或预算。保持/提高年化并改善回撤优先，收益下降只供用户权衡，不自动上线。
