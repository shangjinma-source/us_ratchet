# 牛熊区间补齐成本比较

本轮只读本地已取得资料，无经济搜索、不按策略收益挑年份。用户未限定年份。结论：不应只押注2007旧数据；优先对2021—2023的11个明确行情缺口做一次短清单补齐验证：连续覆盖上涨、2022熊市及恢复，满足用户未限定年份的阶段要求。2007与2020起点保留为后续可选扩展，不强制多轮牛熊或金融危机。

## 可复现行情路线计数

现代区间按冻结社区CSV各有效成员段取并集，与既有Yahoo实际响应及五条已查身份的更名查询路线对照；并集不等于认证成员，别名路线不等于完整行情。结果保存在 `tmp/period_feasibility_20261025/modern_candidate_counts.json`。

| 区间候选 | 成员标签 / 段 | 尚无所需区间行情路线 | 主要增量 |

| 2018—2023 | 157 / 30 | 20 | 比2020起点多8个早年退市缺口；现存WIKI在2018-03终止，无法补后续 |

## 2007路线与现代路线不可直接比较的限制

旧诊断实际是2007年12月决策至2010年11月，原135标签分母已发现LMCK/NDOI时间污染，不能继续把36或22缺口当认证数量。此前22无线索标签已从QSTK取得GENZ/BMC/JAVA/LIFE/TLAB与JOY候选，LMCK/NDOI属于分母审查而非补价，故剩14个实质行情标签线索缺口，但仍受官方锚点/正向成员链重建影响。这14不是已认证全集的最终缺口数。

已扫描WIKI子集有18个拆股记录、497个非零股息记录；数量覆盖2006-12至2011-01子集，不冒称2007—2009全池。普通拆股与股息隔离账法已建设，合并退市、现金/股票对价、旧代码复用及支付日期仍待核。早期官方锚点未认证与Novellus/NVDA身份冲突是新增数据成本，不能靠删股消失。

现代12个缺口中有明确收购/终止交易情形，现有引擎虽有部分合并权益支持，不代表这些事件参数与支付时间已齐。**现代区间尚无逐池行动完整性清单，行动缺口数量未知，绝不是0。** 现代日期表也继承社区源问题，须独立锚点和官方变更审查；不过没有理由先把旧名单的LMCK问题推定到所有现代区间。

## 训练预热复用与最短执行路径

1. 现代已下载2017—2023行情可直接支持2021首个决策之前的253收盘检查；WIKI不需再下载。晚上市证券不能伪造253日历史，应按当时统一资格规则处理。2018首窗的2017年只有约一年，仍需实际数满253个收盘，不能假定足够。
2. 旧WIKI子集2006-12开始足以为2007年底起点提供候选253日预热；**无法支持2007年初连续回测的首窗**，需另从已有完整归档抽取2006甚至更早资料。无需网络但成员身份仍未解决。
3. 下一轮优先对上述11只现代缺口按真实存续期查公开存档，先拿一只具备2020预热至终止的完整原始样本来决定路线是否可扩展。不能继续以2018截止WIKI反复声称补齐2020行情。
4. 并行建立2020年末官方Nasdaq100锚点及2021—2023变更表，精确重算11标签是否都是合法需求，保留差异，不从价格反推成员。
5. 当任一路线完成明确全池数据/行动矩阵，冻结连续区间、预热、缺口处理与基准/候选共用账法，再跑一次经济对照。若现代完整归档无法找到，回到已投入较多工作的2008路线；在比较结果出来前决定区间，避免挑收益。

这只是补齐成本和下一步排序，不保证2021路线必然更快，也不认定现有任何区间已正式准入。当前最省成本的是一次11标签现代归档可行性验证，而不是继续无限找2007单票或直接启动不完整经济回测。

2021域污染判断：目前未发现该范围出现LMCK/NDOI的既知早期错误，但这不是完整认证。现代名称回填、身份延续、退市后标签仍可能有问题，需2020末官方锚点正向复核15段；不能以旧范围坏过直接判现代全坏，也不能因现代快照数量合理判其正确。
