## 扩展决定

官方完整财报获取具有实际可行性，但Tesla的成功不能推出其他公司全部可取。停止每轮两份的无期限模式，下一批按现有39条队列一次登记剩余35条的发行人、类型、已知官方入口和缺失状态，进行有预算的统一获取，而非继续构建新规则。先复用缓存，单URL不重试，单请求不超过15秒；最多35次原文请求，最多12次来源定位查询，到限即交付覆盖表和缺失表，不自动扩预算。

本批资料必须保留不同类型，缺失不算中性，不以文本情绪直接改仓。获取完成后只有在事件覆盖与固定可执行规则共同成立时才启动经济对照。尚无新闻策略收益改善证据，真实账户和生产策略不变。
