## 单位边界不能省略

训练价格坐标与实际决策金额价格可能相差固定比例，后窗例如部分月份的BKNG为25倍、CRWD为4倍，AZN/HON为1/2。风险估计使用同一窗口内的相邻价格比；金额权重使用已绑定的decision_cost，不能直接把训练末价作为交易价格，不能跨月拼接不同坐标的数组。

早窗初次检查遇到两项技术假设错误：被排除候选可以缺少security_id，以及训练末价不一定等于实际决策价。已分别改为仅验证实际选择域内的唯一身份、显式核对decision_cost并记录坐标比值，没有删除实际可选证券或篡改价格来通过。坐标比例记录不等于独立认证全部历史公司行动；已有条件性假设继续保留。

## 用户新增要求：覆盖牛熊两市

扩大尺度的目标是覆盖完整上涨、持续下跌、震荡及急跌反弹过程，不是仅增加类似行情的月份。当前约两年半的两窗不能证明跨完整牛熊周期适用，已有窗口也都被多次查看，不能改名为样本外。

后续长历史应遵守：

1. 先核对能取得哪些时期的历史股票成员、退市、IPO和公司行动资料；不可把当前101只名单直接回填长期历史。若只有固定现有名单，必须明确偏差，不能当正式跨牛熊验证。
2. 时间范围和行情分组规则在看到候选成绩前冻结；上涨、下跌和反弹均保留，不只挑策略表现好的区间。允许用事后市场状态标签解释结果，但不能将未来牛熊标签输入交易信号。
3. 机制筛选窗口与未参与选择的检验窗口分开；一旦根据检验结果修改策略，该段不再是未见样本。
4. 分别报告各类行情的收益、年化、最大回撤、恢复时间、最差月及交易次数，再报告完整连续路径。入金提款进行流量调整，不把它们混入收益或回撤。
5. 保持或提高年化仍为优先目标；收益下降但回撤改善仅进入用户权衡表，不自动采用。不能用牛市大赚掩盖熊市失控，也不能用长期空仓制造低回撤后忽略增长损失。
6. 长历史不自动继承无限运行额度。先完成一次数据覆盖清单，明确可验证年份与缺口，再提交固定运行清单；不扩充参数网格，不动现有V27与真实事件验收安排。

当前通过的是现有31个月内部训练输入预检。完整牛熊历史覆盖、相对波动经济成绩及独立样本外验证均尚未完成。
