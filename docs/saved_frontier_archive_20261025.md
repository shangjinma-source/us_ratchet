# 保存候选提案的隔离研究归档

2026-10-25。已实现独立提案的来源字节核验、原子归档、严格重读和幂等检查。**默认关闭，未接入生产选股、运行配置、日常建议或订单入口。** 原生月目标和原提案完整保留，当前账户配置不变。

## 接口与边界

新增 `data/saved_frontier_policy_archive.py`，复用现有纯函数 `build_frontier_proposal`、规范化编码和路径链接检查。写入接口为：

```python
archive_saved_frontier_policy(
    research_root=明确的隔离目录,
    target=原生月目标,
    proposal=原始独立提案,
    source_files={逻辑来源名称: 原始bytes},
    enabled=False,
)
```

未显式设为 `True` 时不创建目录、锁或归档。开启后，输出目录必须是本仓库 `tmp` 下已经存在的独立子目录；拒绝目录逃逸、符号链接和 Windows 重解析路径。来源使用显式字节映射，不自动搜索文件、不访问网络。完整来源集合是原输入 `source_hashes` 与原月目标 `runtime_pins` 的并集，重名异哈希、逻辑名称别名、缺失或额外来源均拒绝。

模块重新生成并核对纯数学提案，检查原目标、决策、输入的三个内容ID和完整提案ID，逐份核验来源字节。物理来源文件按 SHA256 命名，逻辑来源名称不作为写入路径。每个原目标只允许一个确定提案归档；完全相同的重试返回相同结果，已有完整归档有冲突或损坏时不覆盖、不修补、不退回其他目标。

写入使用每目标独占锁。全部文件在独立临时目录中写入、刷新并核验，完成后按本机文件系统的目录重命名语义一次发布；发生故障则保留未发布目录供诊断。读者只接受完整正式目录，不接受临时目录。并发写入遇到同目标锁会明确拒绝，需调用方决定是否稍后重试。

只读接口 `read_saved_frontier_policy(research_root=..., target_id=...)` 再次核验完整布局、原目标、提案、来源及实现字节。单文件、总来源和归档总量均有上限，读取累计超限时在下一份文件读入之前拒绝。重读要求与归档相同的实现字节；以后实现变化时会严格拒绝，需匹配版本或另行明确迁移复核，不自动升级旧档案。

这里的 `source_bytes_verified=True` 只表示字节与原保存哈希一致，**不证明金融资料真实性、原运行环境已准入或生产策略已采用**。原提案中的 `source_bytes_verified=False` 保持原样；归档结果始终保留 `source_authenticity_verified=False`、`original_runtime_admitted=False`、`production_admitted=False` 和 `policy_execution_enabled=False`。
