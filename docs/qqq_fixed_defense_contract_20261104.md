# 固定QQQ防御基准：一次对照

问题：同一市场过滤放在V27仍有很深回撤，是否主要来自集中选股风险？固定比较QQQ持有与QQQ十个月月末趋势过滤，作为简单防御基准，不是宣称识别熊市或改变生产。

规则沿用已测试趋势信号：月末收盘高于最近十个完整月末收盘的均值则持有，否则现金。月末信号只能下个交易日开盘执行，不使用同收盘成交；先核实2020暖启动完整。0佣金、每次买卖5bp滑点、现金收益0、不杠杆不做空；两方案相同执行和股息口径。若仅价格收益必须双方排除股息并说明，不称总回报。整股与余额保留。

资金：2020年底初始5万美元，2021至2026首交易日各5万美元，末日2026-07-30。期初现金何时建仓按实际第一个可执行开盘明确记录，不假装已取得前一日持仓收益。结果包括年度资产、2022收益、净值最大收盘回撤、恢复期、本金水下时间和成交笔数；2025末单列。不得与此前比例估算细小差异混淆。

固定两方案、一次计算，不扫描均线、仓位或止盈参数；数据不全就报告缺口。没有以回测满足30%为停机目标，允许结果否定该防御方案。既有样本反复查看，非独立样本外；没有未来收益或回撤保证。

规则历史依据可参考作者Meb Faber对其研究的介绍：https://mebfaber.com/2017/12/13/episode-86-quantitative-approach-tactical-asset-allocation/ 。作者介绍月末价格与十月均线比较、弱时转现金；这里单一QQQ及具体交易/成本实现属于本项目固定实验，不冒充原论文全部资产和执行设定。
