## 当前高收益究竟来自哪里

选股器最大化历史价格情景的平均对数期末财富。输入来自253个已完成交易日，分成12段不重叠的21日价格相对变化。它在现金预算、整数股和同一发行人不重复的约束下搜索，再应用月度单股票50%上限和20%收盘峰值退出。它没有直接把组合最大回撤、行业风险或基本面质量写进优化目标。

代码依据：`backtest/return_priority_monthly_training_inputs.py` 的 `values[i + 21] / values[i]`；`backtest/return_priority_fresh_cash_quantity_search_v2.py` 的 `TRAINING_PRICE_SCENARIO_MEAN_NET_LOG_WEALTH`；`backtest/continuous_guided_account_decision.py` 的原8192次预算与额外32步候选；`core/monthly_risk_sizing.py` 的配置时50%裁剪。平均对数财富本身会惩罚情景中的亏损，但它不是逐日路径最大回撤约束；搜索也不证明全局最优。

原始两窗口的31个月度输入都只有12个训练情景。早窗每月93～95个候选，后窗101个；实际月度目标通常只有1～2只，最多3只。场景日期均不晚于决策日，本轮没有发现这些输入直接把未来日期价格列为训练情景。完成收盘后决策、下一开盘才执行的时序也与保存账本一致。这些时序检查不能证明样本当时已经可以在美国市场普通交易：另一个agent的输入资格审查已经找到FER上市前和GEHC的when-issued日期反例，详见 `tmp/drift_cap_research_20261025/input_universe_independent_audit.json`。原两窗没有实际成交这两股，不代表其进入搜索候选域完全没有影响。

但12个情景并非足够多的独立未来样本。在大量股票和组合上选择历史最高分，容易偏向该段历史中的强势股。固定随机种子、精确分数运算和更多候选搜索只能解决可重复性及搜索覆盖，不能证明所选组合未来仍有相同优势。

## 更具体的历史可信度问题

**早窗存在已明确标记的幸存者偏差。** 上游 `tmp/conditional_calendar_year_inputs_20261016_v2/source_manifest.json` 的 `selection_basis` 是 `FIXED_CURRENT_OBSERVED_101_SURVIVOR_BIASED`，文件SHA256为 `7efda5ec222aa200775664be4640585819db0a3224c89e5f2ff8e176649b2433`。该研究首先从当前观察到的101只股票回溯，再应用历史数据和训练资格条件；每月93～95只的变化不代表恢复了完整历史指数成员。

使用现有QQQ基金持仓报告与当时官方变更得到的2023-12-29参考集合，已解析101只。它与早窗首次93只候选重合78只：实际候选独有15只，参考集合独有23只。实际独有包括APP、MSTR、RKLB、PLTR、STX和WDC；参考独有包括BIIB、DLTR、ILMN、SIRI和WBA。该参考仍不是已认证的完整指数成员真值，不能直接将全部15只判作错误纳入、将全部23只判作必须补入。

两处已有更直接的日期证据：

- APP纳入指数的已核生效日期是2024-11-18，[Nasdaq于2024-11-08公布](https://www.nasdaq.com/press-release/applovin-corporation-join-nasdaq-100-indexr-beginning-november-18-2024-2024-11-08)。保存原文SHA256为 `ad3a669c51d0b72c98a2badacb8829b1bcdf3f7a6f27a577b2d1f7a6723dfd3b`。
- MSTR纳入指数的已核生效日期是2024-12-23，[Nasdaq于2024-12-13公布](https://www.nasdaq.com/press-release/annual-changes-nasdaq-100-indexr-2024-12-13)。保存原文SHA256为 `c595531f4aecf66bc8da643a357ef77a8c5fb0f6920ba1696bea34a52465a947`。

本轮重读并复核了这两个原始归档哈希。当前退出规则早窗共有20条目标、12个决策月在这两只股票上述加入日期之前已选中它们。

这不等于用户在这些日期不能买两只股票：用户只要求交易美股，没有把“当时必须是纳指100成分股”设为硬约束。问题是**当前精选股票池的回溯成绩不能冒充当时可构造的完整指数池成绩**。若策略定位本来就是当前科技成长股观察池，仍可研究这个池，但必须公开其事后选池性质；不能为了修正报告而偷偷改变用户投资域。

后窗的上游不同：`tmp/next12_candidate_source_manifest_20261014_v1.json` 使用 `DATED_OFFICIAL_EVENT_CHAIN_CONDITIONAL`，同时 `membership_completeness_certified=false`。它比“固定当前名单回溯”多一层日期事件链，但仍缺完整初始名单及事件覆盖证明。两窗不应被笼统描述为同等质量的点时回测。

补证应集中于有决定性的文件：起始日可核验的完整成员快照、此后完整生效事件链、各证券身份与当时价格单位。现有基金持仓参考只能辅助；已知GRAL精确移除日期和事件覆盖缺口没有被本次诊断修复。不要再无限逐个名称搜索，也不需要用户再次购买历史数据服务。

此外，两窗口已经被用于多次研究方向筛选，后来提出的候选也受到观察到的回撤路径启发。A现已因后窗收益下降被拒绝；任何后续候选即使通过同口径筛选，也不能把这些反复查看过的历史窗口重新叫作独立样本外测试。

## 最多一个成员日期敏感性诊断：仅设计，未执行

如果需要量化早窗基准对事后选池的依赖，可使用一个明确标记的替代候选域：在APP的2024-11-18、MSTR的2024-12-23之前，不允许新选择这两只股票；其余规则及候选不变。日期门槛适用于决策日；按现存月末锚点，两者最早允许的决策日分别为2024-11-29和2024-12-31。只做早窗19个月，按新分支净值重选，费用1bp、滑点10bp、原下一开盘模型保持一致，不叠加A，不搜索日期或扩充排除名单。

这不是“已修复为无偏回测”，更不是用户必须遵守的新交易资格。它只测量一个有可核验日期的候选域扰动对基准的影响。新增规则确实改变了投资域，结果可能高也可能低；目的不是寻找更高收益或用坏结果否定两只股票。任何改善都不能作为生产采用依据。

已检查的现有文件只有这两加入日期的归因、成员参考诊断及后窗事件链构造，没有找到相同两股日期门控的完整经济实验。实施前仍要固定输入、复核两日期的原文、明确最早允许的月度决策日，预登记最多19次新选择并限定一次运行。当前只保留设计，未修改A、基准或生产候选池。
