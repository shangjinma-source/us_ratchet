# 相对方差月度仓位：固定运行清单

2026-10-25。状态：实现与集成验收中，尚未启动经济对照。生产仍为V27。本清单固定问题、参数和预算；运行前仍需生成输入及代码SHA256清单并通过独立账本审阅预检。

## 要回答的问题

在保持V27选股及20%月内退出机制的情况下，月末根据组合近期风险降低目标股数，能否保持年化并降低最大回撤？本批仅筛选是否值得继续，不证明主动择时优于单纯降低仓位。

## 唯一候选B

- 每次正常月度决策先根据该分支真实模拟现金与持仓重新运行V27选股；不复用资金已经不同的旧目标。
- 取该次V27目标的决策金额权重，先合成252个简单日收益，再计算最后21个与全部252个收益的样本方差，分母分别20、251。
- 倍率为`min(1, 方差252 / 方差21)`，不是波动率比，不加杠杆。短期方差为零时倍率1；全现金保留现金。
- 每只目标数量乘同一倍率后向下取整，保留零数量键。现金收益仍按原研究模型为0。展示的方差属于归一化股票篮子，不称为账户风险上限。
- 倍率仅月末更新，月内不因波动恢复而补仓；20%退出优先，同月禁止买回。新月照原规则重置。
- 拆股沿原目标与风险峰值迁移路径。反向拆股导致非整数目标等原模型不支持的情况，明确阻塞并保留，不静默修补。
