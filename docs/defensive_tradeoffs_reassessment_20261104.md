# 新偏好下复查既有防御结果

本轮只读复用已完成回测，不新增计算或参数。用户最新愿意错过部分上涨以减少熊市损失，但30%尚非硬性生产阈值。过去“年化降低即否决”的理由不能独自代表当前偏好，需连同回撤和恢复体验重新评价；不篡改原实验结论或自动采用旧候选。

已有固定QQQ十月趋势过滤，使2022年度收益从V27的-41.13%改善至-10.37%，但2021收益仍同为-14.83%，早窗最大回撤仍57.40%。后窗年化从55.94%降至37.09%，回撤从43.38%降至37.74%。来源：docs/long_market_trend_result_20261026.md。它证明一种市场过滤曾降低该年损失，但既不能证明提前识别所有熊市，也没有保护住组合全部风险。

既有趋势+再买入组合早窗年化-5.46%、回撤57.49%，后窗45.14%/27.36%。来源：docs/candidates/reentry_trend_combination_result_20261104.md。不能只展示后窗低于30%而遗漏早窗57.49%；允许牺牲收益也不使该方案自动适合用户。

既有亏损归因显示：早窗峰谷损失约51.70%由MRNA贡献，后窗约88.52%由APP贡献；最大收盘单股权重约62.33%/61.48%，跨月重复买回与月度峰值重置会累积损失。来源：docs/drawdown_mechanism_20261027.md。市场趋势与个股/组合集中风险不是同一问题，单独加市场开关不能替代组合约束。

本轮结论：已有证据支持把熊市防御、集中风险和盈利回吐分别列为问题，但不支持立即替换生产。下一项若获选应是规则明确、数量有限的固定对照，并将QQQ作为简单基准；不围绕10月均线或退出等待天数连续扫参，不以未来跌幅选择阈值。新增实验前先明确与已有机制的差异及收益代价，当前没有启动。
