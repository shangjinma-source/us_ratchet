# ROA策略与回测

整理日期：2026-11-08。当前策略标识为 `ROA_DEFENSIVE_V1`；本文描述规则与既有结果，不代表本次重新回测。

## 规则

| 环节 | 当前规则 |
|---|---|
| 资格 | 使用可获得的财务资料，净利润、经营现金流及期末资产为正；缺资料不猜补 |
| 排序 | ROA（净利润/期末资产）百分位与252/21中期动量百分位各50%；同分按证券身份排序 |
| 配置 | 月度选股，最多10个不同发行主体，单股目标10%；不足10只时保留现金；整股、无杠杆 |
| 市场状态 | QQQ收盘价相对SMA200，连续两次收盘同方向确认；下一开盘切换股票或现金 |
| 个股退出 | 月内持仓峰值回落20%后，安排下一交易日收盘退出；市场退出和月度减仓可在OPEN优先执行 |
| 再买入 | 止损退出后本月不买回；次月解除禁入，未完成的退出仍保留，不允许趁机加仓 |
| 实盘执行 | 开盘参考计算OPEN目标与限价；刷新时重新核对账户、当前报价、整股和现金；卖款未到账不假定可用 |

月度选股不等于每月一定全部换仓。市场状态和个股退出可在月内改变持仓。20%个股退出阈值也不是账户最大回撤的保证。

## 如何看待结果

- ROA相对V27牺牲约0.67个百分点年化，显著减少历史回撤；成交笔数更多，尚未解决操作频繁的问题。
- 全期收益和回撤均优于QQQ，但截至2025年末ROA年化约10.02%，QQQ约14.94%。超额依赖2026，不能称为各市场阶段稳定胜出。
- 收盘回撤不是盘中回撤；历史数据时点、股票池覆盖与财务版本仍有条件性限制。算术复核不等于独立样本外验证。
- 未计真实汇丰佣金与股息税。盘中挂单、滑点、部分成交和限价不成交会使实际结果偏离回测；扩展盘中刷新并未重新证明经济效果。
- AI新闻复核目前不作为已获收益证据的策略优势。
