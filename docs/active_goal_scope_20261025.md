# 当前 Goal：真实账户闭环与牛熊策略验证

2026-10-25 用户恢复推进并要求多 agent 执行。本文件补充原 Goal 的研究要求，不替换真实账户闭环，也不把研究完成等同整个 Goal 完成。

## 最高优先级：不依赖开盘的工作继续推进

1. 完成涵盖有代表性牛市、熊市及转换阶段的当前个股策略回测。用户未限定年份；2018—2023只是此前研究设计候选。实际连续区间依据数据覆盖与市场阶段选择，在查看候选成绩前冻结，不为改善结果移动起点。
2. 以当前V27为基准，研究保持或提高年化同时降低最大回撤。展示收益、最大回撤、恢复时间、现金和成交代价。用户追加授权：证据充分且完全有利的方案直接接入、验证并采用，不再请求重复批准；判定至少包括同口径年化不降低、回撤改善、无明显新增执行代价，不能只凭单个有利窗口或未核验数据上线。存在收益或其他实际代价取舍的方案仍列出交换幅度，由用户决定。
3. 主动查找免费历史数据，包括GitHub项目、公开归档、历史成员和退市公司行动。调查项目实际数据及来源，不只列链接，不运行不明第三方代码，不购买订阅。
4. 数据必须能够重建当时选股资格、可交易状态、价格及持仓权益。不得删除失败证券、以现代幸存者池替代历史成员，或以ETF回测替代V27个股验证。
5. 广泛比较成熟研究机制，先审查解释力、执行适配及已有反证，再冻结有限实验。每项实验列规则、输入、费用、执行模型、预算及停止条件；不无界调参，不因一条数据路线失败就将全部研究归为等待开盘。
6. 可落地工程、来源校验、独立复核及简易文档继续推进；完成品按已有授权提交GitHub，私人账户和原始数据留本地。明确区分研究通过、工程接入、已启用和真实事件验收。
