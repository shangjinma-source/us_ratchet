# 执行计划日期与最新信号

接口的 signal_date、execution_session、执行窗口统一属于实际展示的执行事件。market_signal 保留最新收盘判断；execution_event 明确历史事件身份和日期。

例如周五只完成部分买入、周末更新到周一信号时，未完成的周五计划仍标注周五，不能显示为周一已经错过。此修复不重新开放过期计划、不自动补买、不更改账户现金或成交。

验证：部分成交后跨周末 HTTP 回归、20 项盘中执行测试、6 项延迟执行测试、前端历史日期及无可执行动作断言通过。
