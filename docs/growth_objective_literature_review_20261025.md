# 当前收益目标与成熟投资研究的对应关系

2026-10-25。本页解释现有算法，不新增候选、参数或回测，也不改变生产策略。

## 现有目标属于哪一类方法

当前选股使用253个收盘价格，形成12个不重叠的21交易日价格情景，最大化这些情景下期末财富的平均对数。用账户可交易资产价值作为假设初始资金，扣除建仓费用，剩余现金和各股情景市值构成期末财富；整数股、同发行人不重复等限制仍然存在。

这是代码层面的判断：它与增长最优、Kelly类目标有直接联系，但不是对Kelly理论条件的完整复刻。Kelly原文研究通过最大化对数资本增长选择投注比例。[Kelly，1956，原文](https://www.princeton.edu/~wbialek/rome/refs/kelly_56.pdf)

当前实现的明确差别是：12个历史情景被等权使用，这不是已经验证的未来概率分布；每月会重选，存在费用、整数股和有限候选搜索；选中后还有50%单股数量裁剪、20%退出。有限搜索不证明全局最优，事后裁剪也不保证保留原排序。增加搜索次数只可能改善给定样本中的搜索结果，不能增加独立市场观察。

代码依据：`backtest/return_priority_monthly_training_inputs.py`、`backtest/return_priority_fresh_cash_quantity_search_v2.py`、`backtest/continuous_guided_account_decision.py`、`core/monthly_risk_sizing.py`。实际31个月度输入每次均为12个情景，见[机制审查](strategy_mechanism_review_20261025.md)。

## 三个容易误用的结论

**单股50%裁剪不等于半Kelly。** 半Kelly是对原风险资产配置整体缩放并增加现金；现有规则只裁剪超过单股限额的股票。两只各占50%的股票仍可占满整个账户，不能把“单股50%”解释为“组合风险减半”。当前实现也没有根据估计误差计算Kelly缩放比例。

**论文的回撤约束不一定是本工具的最大回撤。** Busseti、Ryu、Boyd研究的是固定比例、独立同分布收益条件下，财富跌破初始财富某比例的概率约束。原文第3节把回撤定义为相对初始财富的下跌；本工具报告的是逐日净值相对此前运行高点的最大下降，二者不能互换。即使直接加入论文公式，也不能宣布账户最大回撤得到保证。[Risk-Constrained Kelly Gambling，第2—5节](https://web.stanford.edu/~boyd/papers/pdf/kelly.pdf)

**稳健优化仍需要事先确定不确定性范围。** Sun、Boyd把概率分布设为一个集合，并优化集合内最不利的对数增长。这提供了处理分布估计误差的思路，但集合的选择本身就是建模假设，不能由本工具已看过的两段收益反复挑选。[Distributional Robust Kelly Gambling](https://web.stanford.edu/~boyd/papers/pdf/robust_kelly.pdf)

## 对本轮迭代的实际作用

1. 已完成的“同次保存候选限仓后重排”只处理目标与限制应用顺序；它没有解决12情景估计误差、事后选池或未来分布改变。历史筛选通过也不能升级成未来收益保证。
2. 月内价格上涨后的持续减仓是另一种风险控制。A已被同口径结果拒绝，不因其听起来像Kelly缩放而继续调整阈值。
3. 波动管理、趋势、质量和风险约束解决不同问题，不能把多个名称叠加便称为成熟策略。前两者已有相关旧证据，质量需要当时可得的基本面；本轮没有据此开启新的参数网格。
4. 后续判断应同时看收益、全窗及分歧后回撤、现金暴露、成交负担和真实执行条件。任何一个未定义的风险偏好参数都不能偷偷从回测最优值反推为用户偏好。

本页的一手文献提供机制与适用边界，当前工具的效果仍以保存账本、独立复核和真实验收分别判断。没有新增经济运行，也没有声称现有策略具有论文中的风险保证。
