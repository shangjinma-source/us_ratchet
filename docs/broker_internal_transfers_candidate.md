# 双券商转账记录（候选，未部署）

## 本轮实现

- “操作与持仓”新增默认折叠的转账记录入口，支持汇丰与盈立之间已转出、部分到账及全部到账。
- 输入本金、另行扣除的费用和实际发生时间；历史记录展示已到账和在途金额。
- 独立 SQLite 日志，不修改策略账户现金、成交或委托，不发起银行转账。
- 保存响应丢失先查回；不能确认时冻结输入并沿用原事件编号重试，避免重复记账。
- 服务挂载受现有源码校验约束，新文件已纳入候选 V34 必需源码清单。
